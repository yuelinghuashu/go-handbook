# 20 字符串与字节

> Go 版本：>= 1.27.1  
> 相关标准库：strings、bytes、strconv、unicode、unicode/utf8、iter

从这一篇开始进入标准库专题，**读法也变了**：这里不是必须按顺序读的教程，而是按任务组织的参考，可以按需跳读（读法说明见 `README.md`），每篇开头一句说明它解决哪几类问题。本篇解决文本处理：`strings`/`bytes` 的常用操作、字符串与字节切片的转换、`strconv` 的数字转换，以及 `unicode`/`utf8` 的字符判断。

## 字符串的本质

字符串是不可变的字节序列，通常保存 UTF-8 编码的文本。

```go
s := "Go语言"

fmt.Println(len(s)) // 8
```

索引字符串得到字节：

```go
fmt.Println(s[0]) // 71
```

`range` 遍历字符串得到 `rune`：

```go
for i, r := range s {
    fmt.Println(i, r) // 0 71 / 1 111 / 2 35821 / 5 35328 —— 索引是字节位置，不是第几个字符
}
```

`range` 一次解码一个 rune，遇到非法 UTF-8 字节时给出 `utf8.RuneError`，见下文“非法 UTF-8 的行为”。

`string`、`byte`、`rune` 三个类型本身的定义与别名关系（`byte` 即 `uint8`、`rune` 即 `int32`）见 `01-变量与基础类型.md` 的“byte 和 rune”一节；本篇讲的是它们作为文本使用时要注意的行为。

## strings 常用函数

### 前缀、后缀与包含

```go
s := "golang"

fmt.Println(strings.HasPrefix(s, "go")) // true
fmt.Println(strings.HasSuffix(s, "lang")) // true
fmt.Println(strings.Contains(s, "lan")) // true
```

### 查找

```go
fmt.Println(strings.Index("golang", "lang")) // 2
fmt.Println(strings.LastIndex("golang", "g")) // 5
```

不存在时返回 `-1`。

### 大小写与修剪

```go
// ToUpper / ToLower：整体转大写 / 小写，Unicode 感知
fmt.Println(strings.ToUpper("go"))   // GO
fmt.Println(strings.ToLower("GO"))   // go
// TrimSpace：去掉首尾空白；Trim：去掉首尾出现在 cutset 里的任意字符
fmt.Println(strings.TrimSpace("  go  ")) // go
fmt.Println(strings.Trim("xxgoxx", "x")) // go
```

### 分割与拼接

```go
parts := strings.Split("a,b,c", ",")
fmt.Println(parts) // [a b c]

joined := strings.Join(parts, "-")
fmt.Println(joined) // a-b-c
```

只遍历结果、不需要整个切片时，用 Go 1.24 的 `strings.SplitSeq`，见下文“迭代器版分割 API（Go 1.24）”。

### 替换与重复

```go
fmt.Println(strings.ReplaceAll("go go", "go", "run")) // run run
fmt.Println(strings.Repeat("go", 3)) // gogogo
```

### NewReplacer：一趟完成多处替换

`strings.NewReplacer` 接收成对的 old/new 参数，用一次遍历同时替换所有模式：

```go
r := strings.NewReplacer("<", "&lt;", ">", "&gt;", "&", "&amp;")

fmt.Println(r.Replace("<a & b>")) // &lt;a &amp; b&gt;
```

参数个数为奇数时 `NewReplacer` 会 panic。它从左到右扫描目标串，匹配不重叠；同一位置有多个模式都能匹配时按参数顺序优先（`NewReplacer("ab", "X", "a", "Y").Replace("ab")` 得到 `"X"`）。`Replacer` 可以并发使用，适合只构造一次并做成包级变量。

对比链式 `strings.ReplaceAll`：

```go
s := strings.ReplaceAll("<a & b>", "<", "&lt;")
s = strings.ReplaceAll(s, ">", "&gt;")
s = strings.ReplaceAll(s, "&", "&amp;")

fmt.Println(s) // &amp;lt;a &amp; b&amp;gt;
```

链式写法每调用一次就完整遍历并分配一次结果，而且会把前一步插入的 `&` 再转义一遍（上面结果已经错乱）。`NewReplacer` 一趟扫描、只分配一次，模式越多优势越明显，也避免了互相污染的转义顺序问题。

```go
var buf strings.Builder

n, err := r.WriteString(&buf, "<a & b>") // 直接写入 io.Writer，不额外生成字符串
if err != nil {
    fmt.Println(err)
    return
}

fmt.Println(n, buf.String()) // 17 &lt;a &amp; b&gt;
```

### Cut 系列

```go
before, after, found := strings.Cut("key=value", "=")

fmt.Println(before, after, found) // key value true
```

`CutPrefix`、`CutSuffix` 从 Go 1.20 起提供；Go 1.27 新增了 `CutLast`（`strings` 和 `bytes` 都有）：

```go
rest, ok := strings.CutPrefix("go:lang", "go:")
fmt.Println(rest, ok) // lang true

before, ok := strings.CutSuffix("main.go", ".go")
fmt.Println(before, ok) // main true

head, tail, ok := strings.CutLast("a-b-c", "-")
fmt.Println(head, tail, ok) // a-b c true
```

## 字符串的构造与拼接

### 用 + 拼接字符串

`+` 运算符可以直接拼接两个字符串，结果是新字符串：

```go
s := "go" + "-" + "lang"
fmt.Println(s) // go-lang
```

但 `+=` 在循环里每一轮都会重新分配并复制整条字符串，长度越大越慢：

```go
var s string
for i := 0; i < 1000; i++ {
    s += "x" // 每轮都分配一次
}
```

需要循环拼接时改用 `strings.Builder`。

### Builder

大量拼接字符串时，使用 `strings.Builder` 减少内存分配：

```go
var b strings.Builder

b.WriteString("go")
b.WriteString("lang")

fmt.Println(b.String()) // golang
```

已知大致长度时先 `Grow` 一步预留容量，可以避免中途扩容：

```go
var b strings.Builder

// Grow：预留 n 字节容量；WriteString / WriteByte / WriteRune：按类型追加
b.Grow(64)
b.WriteString("go")
b.WriteByte('-')
b.WriteRune('语')

// String：取出结果；Len / Cap：看已写入的字节数与底层容量
fmt.Println(b.String(), b.Len(), b.Cap()) // go-语 6 64
```

`Builder` 的零值即可使用，但**第一次使用之后不能再复制**：复制出来的非零副本一旦再写入就会直接 panic（`strings: illegal use of non-zero Builder copied by value`），因为内部的字节切片会被两个副本共享。这道检查是运行期的动态检查，编译器与 `go vet` 都不会提前报错，只能靠约定，因此永远用 `*strings.Builder` 传递它。

`Builder` 与 `bytes.Buffer` 的分工：

- 构造字符串：用 `strings.Builder`，`String()` 不额外复制。
- 需要读取侧能力时用 `bytes.Buffer`：它额外提供 `Read`、`ReadByte`、`Next`、`Bytes`（拿到底层切片）和 `WriteTo`，可以当 `io.Reader`/`io.Writer` 两边用。

### strings.Reader：把字符串当成 Reader

`strings.NewReader` 返回的 `*strings.Reader` 实现了 `io.Reader`、`io.ReaderAt`、`io.ByteReader`、`io.RuneReader`、`io.Seeker`、`io.WriterTo`，可以把一个字符串直接喂给只接受 reader 的 API（`io.Reader` 与 `io.ReadFull` 的细节见 `21-io与流.md`）：

```go
r := strings.NewReader("Go语言")

buf := make([]byte, 2)
n, err := io.ReadFull(r, buf)
fmt.Println(n, string(buf), err) // 2 Go <nil>

off, _ := r.Seek(0, io.SeekStart) // 支持随机定位
fmt.Println(off) // 0

b, _ := r.ReadByte() // 也支持按字节读
fmt.Println(b) // 71
```

常见用途是配合 `bufio.NewScanner`、`io.ReadAll`、`http.NewRequest` 之类的接口做测试。

## bytes 常用函数

`bytes` 包提供与 `strings` 类似的字节切片操作。

```go
data := []byte("golang")

fmt.Println(bytes.Contains(data, []byte("lang"))) // true
fmt.Println(bytes.HasPrefix(data, []byte("go")))  // true
```

分割与拼接：

```go
parts := bytes.Split([]byte("a,b,c"), []byte(","))
fmt.Println(parts)

joined := bytes.Join(parts, []byte("-"))
fmt.Println(string(joined)) // a-b-c
```

只要遍历结果时，同样可以用迭代器版本（见下一节）。

`bytes.Buffer` 常用于读写缓冲：

```go
var buf bytes.Buffer

buf.WriteString("go")
buf.WriteString("lang")

fmt.Println(buf.String()) // golang
```

Go 1.27 也新增了 `bytes.CutLast`：

```go
head, tail, ok := bytes.CutLast([]byte("a-b-c"), []byte("-"))
fmt.Println(string(head), string(tail), ok) // a-b c true
```

## 迭代器版分割 API（Go 1.24）

Go 1.24 为 `strings` 和 `bytes` 加了一组返回迭代器（`iter.Seq`）的分割函数。它们逐个产出元素而不是构造整个切片，可以直接配合 `for ... range` 使用：

| strings                                         | bytes                                           | 对应的旧函数   |
| ----------------------------------------------- | ----------------------------------------------- | -------------- |
| `SplitSeq(s, sep string) iter.Seq[string]`      | `SplitSeq(s, sep []byte) iter.Seq[[]byte]`      | `Split`        |
| `SplitAfterSeq(s, sep string) iter.Seq[string]` | `SplitAfterSeq(s, sep []byte) iter.Seq[[]byte]` | `SplitAfter`   |
| `FieldsSeq(s string) iter.Seq[string]`          | `FieldsSeq(s []byte) iter.Seq[[]byte]`          | `Fields`       |
| `Lines(s string) iter.Seq[string]`              | `Lines(s []byte) iter.Seq[[]byte]`              | 无（新增能力） |

`range` 一个函数值就是 Go 1.23 的 range-over-func（`yield` 与迭代器函数的写法见 `14-迭代器.md`）：

```go
for part := range strings.SplitSeq("a,b,c", ",") {
    fmt.Println(part)
}
// a
// b
// c

for part := range strings.SplitAfterSeq("a,b,c", ",") {
    fmt.Println(part)
}
// a,
// b,
// c

for word := range strings.FieldsSeq("  go is  fast ") {
    fmt.Println(word)
}
// go
// is
// fast
```

`Lines` 按换行切分，**每个结果保留行尾的换行符**，空串不产出任何行，最后一行没有换行符时也不会补：

```go
for line := range strings.Lines("a\nb\nc") {
    fmt.Printf("%q\n", line)
}
// "a\n"
// "b\n"
// "c"
```

`bytes` 版本用法一致，只是元素类型是 `[]byte`：

```go
for w := range bytes.FieldsSeq([]byte("go 1.27")) {
    fmt.Println(string(w)) // go / 1.27
}
```

两个要点：

- 这四个函数返回的都是**单次迭代器**（判断办法与应对见 `14-迭代器.md` 的“能不能重复遍历，取决于迭代器本身”一节）：不要存起来等以后再用；需要切片就套一层 `slices.Collect`。
- 用完即弃时它比 `strings.Split` 少一次切片分配。

工具链已经把它当作首选写法：`go fix` 的 `stringsseq` 重写器会把 `for _, x := range strings.Split(...)` 自动改写成等价的 `for x := range ...SplitSeq(...)`（改写示例和重写器清单见 `00-工具链.md`）。注意 `go vet` 并不会提示这种写法，需要显式运行 `go fix`（或 `go fix -diff` 只看补丁）。

需要随机访问、需要 `len(parts)`、或者要把结果传给别人保存时，仍然用 `strings.Split`。

## strconv 数字与字符串转换

选哪个先看这里：整数与字符串之间、且不需要指定进制时用 `Atoi`/`Itoa`（它们就是 `ParseInt(s, 10, 0)` 和 `FormatInt` 的简写）；要控制进制、位宽，或者要处理 `int64` 边界，用 `ParseInt`/`FormatInt`；浮点用 `ParseFloat`/`FormatFloat`（注意 `FormatFloat` 的精度参数决定保留几位有效数字）；要加引号做转义用 `Quote`。

字符串转整数：

```go
n, err := strconv.Atoi("42")
if err != nil {
    fmt.Println(err)
}
fmt.Println(n) // 42
```

整数转字符串：

```go
s := strconv.Itoa(42)
fmt.Println(s) // 42
```

解析其他进制：

```go
n, err := strconv.ParseInt("ff", 16, 64)
fmt.Println(n, err) // 255 <nil>
```

格式化整数：

```go
s := strconv.FormatInt(255, 16)
fmt.Println(s) // ff
```

浮点数转换：

```go
f, err := strconv.ParseFloat("3.14", 64)
fmt.Println(f, err)

s := strconv.FormatFloat(3.14, 'f', 2, 64)
fmt.Println(s) // 3.14
```

布尔值转换：

```go
b, err := strconv.ParseBool("true")
fmt.Println(b, err) // true <nil>
```

字符串加引号：

```go
fmt.Println(strconv.Quote("go\n")) // "go\n"
```

## unicode/utf8

统计字符数量：

```go
fmt.Println(utf8.RuneCountInString("Go语言")) // 4
```

验证字符串是否为合法 UTF-8：

```go
fmt.Println(utf8.ValidString("Go语言")) // true
```

解码第一个字符：

```go
r, size := utf8.DecodeRuneInString("Go语言")

fmt.Println(r, size)           // 71 1
fmt.Printf("%q %d\n", r, size) // 'G' 1
```

`DecodeRuneInString` 返回首字符的 **rune** 和它占的**字节数**。rune 就是 `int32`，直接打印得到的是码点（`71` 即 `'G'`），要打出字符本身得用 `%c`、`%q` 或 `string(r)`。

### 非法 UTF-8 的行为

`range` 一个字符串时，解码失败的字节会产出 `utf8.RuneError`（U+FFFD，`'\uFFFD'`），但**索引仍然按字节推进**，一个坏字节算一步：

```go
s := "a\xffb"

for i, r := range s {
    fmt.Printf("i=%d r=%U\n", i, r)
}
// i=0 r=U+0061
// i=1 r=U+FFFD
// i=2 r=U+0062

fmt.Println(len(s), utf8.RuneCountInString(s)) // 3 3
fmt.Println(utf8.ValidString(s))               // false
```

每个坏字节各产生一个 U+FFFD，一次只前进一个字节；被截断的多字节字符也是“剩几个字节就报几个替换字符”：

```go
t := "语"[:1] + "文"[:1] // 两个残缺的多字节字符

for i, r := range t {
    fmt.Printf("i=%d r=%U\n", i, r)
}
// i=0 r=U+FFFD
// i=1 r=U+FFFD
```

`len` 与 `RuneCountInString` 在这种输入下可能相等，别把字符数当成字节数。

校验时要区分两个函数：

- `utf8.ValidString(s string) bool` —— 作用于 `string`，日常校验字符串用它。
- `utf8.Valid(p []byte) bool` —— 作用于 `[]byte`，处理从文件/网络读来的字节时才用它。

```go
fmt.Println(utf8.ValidString("Go语言"))  // true
fmt.Println(utf8.Valid([]byte("Go语言"))) // true
fmt.Println(utf8.Valid([]byte{0xff}))    // false
```

两者规则相同（都是“是否全部由合法 UTF-8 编码的 rune 组成”），区别只在入参类型：`string` 用 `ValidString`，`[]byte` 用 `Valid`。

## unicode 包：按 rune 判断字符类别

`unicode` 处理单个 rune 的类别与大小写；`strings` 处理整条 UTF-8 字节串。判断字符类别时先解码成 rune，再交给 `unicode`：

```go
// IsLetter / IsDigit / IsSpace：判断 rune 是否为字母 / 十进制数字 / 空白
fmt.Println(unicode.IsLetter('语')) // true
fmt.Println(unicode.IsDigit('7'))  // true
fmt.Println(unicode.IsSpace('\t')) // true

// 类别不匹配就是 false，不会报错
fmt.Println(unicode.IsLetter('7')) // false
fmt.Println(unicode.IsDigit('x'))  // false
```

这些判断依据的是编译进标准库的 Unicode 表，版本跟随 Go 版本：Go 1.27 对应 **Unicode 17.0.0**，可以用 `unicode.Version` 打印确认。新版本新增的字符在旧工具链上会被判成非字母、非数字，跨版本解析文本时要注意。

大小写转换：

```go
fmt.Println(string(unicode.ToUpper('a'))) // A
fmt.Println(string(unicode.ToLower('A'))) // a
```

`unicode.In` 用一张或多张 `RangeTable` 做成员测试。这些表（`unicode.Han`、`unicode.Latin`、`unicode.Cyrillic` 等）就是按码点区间列出的 `unicode.RangeTable`，`unicode.Is(rangeTab, r)` 是单表的等价写法：

```go
fmt.Println(unicode.In('语', unicode.Han))  // true
fmt.Println(unicode.Is(unicode.Latin, 'A')) // true
```

`RangeTable` 导出 `R16 []Range16`、`R32 []Range32` 和 `LatinOffset int` 三个字段，区间必须有序且不重叠——自己拼表时才需要关心这些细节，日常直接用 `unicode` 里的现成表即可。

`unicode` 的函数都是针对单个 rune 的（入参里总有 `rune`），它不认字节也不认字符串；字符串层面的类别判断（例如 `strings.TrimFunc(s, f func(rune) bool)`）内部也是逐个解码 rune 再调用 `unicode`。反过来说，`strings` 的函数直接处理 UTF-8 字节串，不需要你自己解码。

### 大小写与 ASCII 假设

`strings.ToUpper`/`ToLower` 是 Unicode 感知的（文档写的是 “all Unicode letters mapped to...”），不是只看 ASCII：

```go
fmt.Println(strings.ToUpper("café")) // CAFÉ
fmt.Println(strings.ToUpper("go"))   // GO
```

但 `regexp` 里的 `\d`、`\w` 是 ASCII-only，不匹配阿拉伯-印度数字和汉字；这类字符类陷阱在 `29-命令行与正则.md` 的“regexp”一节里连同例子一起讲。

另外，按字节操作文本会破坏非 ASCII 内容：字符串可能被从多字节字符中间切开，产生非法 UTF-8。

```go
s := "Go语言"

fmt.Printf("%q\n", s[:3]) // "Go\xe8"
```

`"Go"` 后面跟着的是"语"的首字节 `0xe8`，单独拿出来已经不是合法 UTF-8。直接 `Println` 会打印出乱码，所以这里用 `%q` 把字节原样显示出来。

需要截断时要按 rune 边界走（`[]rune(s)`、`utf8.DecodeRuneInString`），或者用 `strings.ToValidUTF8(s[:3], "?")` 兜底（输出 `Go?`）。

## 字符串与字节切片

字符串转字节切片：

```go
data := []byte("Go语言")
```

字节切片转字符串：

```go
s := string(data)
```

字符串转 rune 切片：

```go
runes := []rune("Go语言")
fmt.Println(len(runes)) // 4
```

这些转换**都会复制一份数据**（区别于 `10-指针.md` 里 `unsafe.String` 那种零拷贝转换）。需要频繁转换时，分配成本往往是热点所在——先测量，再决定要不要换数据结构。
