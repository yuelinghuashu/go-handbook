# 06 数组

> Go 版本：>= 1.27.1  
> 相关标准库：unsafe

## 数组是什么

数组是固定长度的同类型元素序列。长度是数组类型的一部分，因此 `[3]int` 和 `[5]int` 是不同类型。

```go
var a [3]int
var b [5]int
```

数组的长度在编译期确定，之后不能改变。需要动态长度时，通常使用切片。

## 声明与零值

数组声明后每个元素都是对应类型的零值（零值清单见 `01-变量与基础类型.md` 的“零值”一节）：

```go
var a [3]int

fmt.Println(a) // [0 0 0]
```

字符串数组：

```go
var names [2]string
fmt.Println(names) // [ ]
```

## 初始化

使用数组字面量：

```go
a := [3]int{1, 2, 3}
```

只初始化部分元素：

```go
a := [5]int{1, 2}

fmt.Println(a) // [1 2 0 0 0]
```

按索引初始化：

```go
a := [5]int{0: 1, 4: 2}

fmt.Println(a) // [1 0 0 0 2]
```

让编译器根据元素个数推断长度：

```go
a := [...]int{1, 2, 3}

fmt.Println(len(a)) // 3
```

`[...]T` 只允许出现在复合字面量里，不能用作函数参数或返回类型：

```go
// func f(a [...]int) {}      // 语法错误（parser 阶段）：expected operand, found '...'
// func g() [...]int { ... }  // 类型检查错误：invalid use of [...] array (outside a composite literal)
```

## 访问与修改

使用索引访问元素，索引从 `0` 开始：

```go
a := [3]int{10, 20, 30}

fmt.Println(a[0]) // 10
fmt.Println(a[2]) // 30

a[1] = 99
fmt.Println(a) // [10 99 30]
```

索引越界会在运行时 panic：

```go
a := [3]int{}
fmt.Println(a[3]) // panic: index out of range
```

## 长度

`len` 返回数组长度。数组的容量等于长度：

```go
a := [3]int{1, 2, 3}

fmt.Println(len(a)) // 3
fmt.Println(cap(a)) // 3
```

长度是类型的一部分：

```go
var a [3]int
var b [5]int

fmt.Printf("%T", a) // [3]int
fmt.Printf("%T", b) // [5]int
```

## 内存布局

数组本身没有头部，也不在元素之间插入额外填充：它就是一段连续的元素，大小正好是"元素大小 × 长度"。相邻元素的地址差正好是一个元素的大小，元素是结构体时步长就是结构体本身的大小（含结构体内部的对齐填充）：

```go
var a [4]int32

// 相邻 int32 元素的地址差是 4
uintptr(unsafe.Pointer(&a[1])) - uintptr(unsafe.Pointer(&a[0]))
```

数组的数组同样是一整块连续内存，第二行紧接第一行。因为布局连续且固定，数组常被用作缓冲区、哈希值和 `[N]byte` 这类定长数据——`[N]byte` 与 `[]byte` 的转换、以及零长数组 `[0]T` 在结构体里的对齐影响，都建立在这个布局之上。

长度为零的数组 `[0]T` 是合法的，不占空间，但如果作为结构体字段出现，它的对齐要求仍可能给结构体带来填充，不要把它当成绝对"免费"。

**用 `unsafe` 实测这些布局**（`unsafe.Sizeof` 打印字节数、用指针差值量步长）的完整示例，连同结构体填充、字段偏移和对齐规则，都在 `36-reflect与unsafe.md` 的“内存布局与 unsafe”一节——`unsafe` 需要先了解指针（`10-指针.md`）。

## 值语义

数组是值类型。赋值、传参和返回时都会复制整个数组（这一点和 Python 的 `list`、JS 的 `Array` 正好相反：那边的变量只是指向同一个容器，这边的数组本身就是数据）：

```go
a := [3]int{1, 2, 3}
b := a

b[0] = 99

fmt.Println(a) // [1 2 3]
fmt.Println(b) // [99 2 3]
```

函数接收数组参数时，同样会复制：

```go
func change(a [3]int) {
    a[0] = 99
}

a := [3]int{1, 2, 3}
change(a)

fmt.Println(a) // [1 2 3]
```

需要修改原数组时可以传数组指针，大数组传值则通常改用切片或数组指针；写法和"该传指针还是传值"的判断标准见 `10-指针.md` 的“避免复制大对象”一节。

## 遍历

使用 `range` 遍历数组：

```go
a := [3]int{10, 20, 30}

for i, v := range a {
    fmt.Println(i, v) // 0 10 / 1 20 / 2 30
}
```

使用 `for i, v := range a` 遍历数组时，`v` 来自数组的副本，循环中修改原数组不会影响本次遍历中的 `v`：

```go
a := [3]int{1, 2, 3}

for i, v := range a {
    if i == 0 {
        a[1] = 100
    }
    fmt.Println(v)
}

fmt.Println(a) // [1 100 3]
```

输出仍然是 `1`、`2`、`3`。如果只写 `for i := range a`，不会为了取值而复制数组；循环体内通过 `a[i]` 读取的是当前数组内容，修改会立即反映出来。遍历数组指针时，修改也会立即反映：

```go
a := [3]int{1, 2, 3}
p := &a

for i, v := range p {
    if i == 0 {
        p[1] = 100
    }
    fmt.Println(v) // 1 100 3 —— 遍历指针时读到的是修改后的数组
}
```

## 比较

如果数组元素类型可比较，那么数组也可以使用 `==` 和 `!=`：

```go
a := [3]int{1, 2, 3}
b := [3]int{1, 2, 3}
c := [3]int{1, 2, 4}

fmt.Println(a == b) // true
fmt.Println(a == c) // false
```

比较会逐个比较元素。数组长度不同，类型就不同，不能直接比较。

```go
var a [3]int
var b [5]int

// a == b // 编译错误：类型不同
```

如果元素类型不可比较，数组也不可比较：

```go
// [2][]int{} == [2][]int{} // 非法
```

## 数组与切片转换

切片可以转换为数组或数组指针（Go 1.20 起），但长度必须足够。切片本身的语法见下一篇 `07-切片.md`，这里只看两者之间的转换规则。

转换为数组：

```go
s := []int{1, 2, 3, 4}
a := [3]int(s)

fmt.Println(a) // [1 2 3]
```

转换为数组指针：

```go
s := []int{1, 2, 3, 4}
p := (*[3]int)(s)

fmt.Println(p) // &[1 2 3]
```

转换的判定依据是**切片的长度 `len(s)`，不是容量 `cap(s)`**：只要 `len(s) < N`，转成 `[N]T` 或 `*[N]T` 都会在运行时 panic，容量再大也没用。

```go
s := make([]int, 2, 4) // len=2 cap=4

// p := (*[3]int)(s)
// panic: runtime error: cannot convert slice with length 2 to array or pointer to array with length 3

t := make([]int, 3, 4) // len=3 cap=4，长度够
q := (*[3]int)(t)
fmt.Println(q) // &[0 0 0]
```

转成数组指针**不复制数据**，指针直接指向切片那段底层数组，通过它写入会影响原切片；转成数组值则是复制：

```go
s := []int{1, 2, 3, 4}

p := (*[3]int)(s)
p[0] = 99
fmt.Println(s) // [99 2 3 4]，原切片被改了

a := [3]int(s)
a[1] = 77
fmt.Println(s) // [99 2 3 4]，值转换是拷贝
```

## 多维数组

数组可以嵌套：

```go
matrix := [2][3]int{
    {1, 2, 3},
    {4, 5, 6},
}

fmt.Println(matrix[1][2]) // 6
```

多维数组也是值类型，赋值时会复制整个结构。

## 使用场景

数组适合长度固定、元素数量已知的场景，例如：

- 固定大小的缓冲区
- 哈希值、校验和
- 矩阵和坐标
- 明确长度且不想额外分配的数据

日常业务代码中，切片更常见，因为切片支持 `append`、动态长度和更灵活的子序列操作。
