# 04 函数

> Go 版本：>= 1.27.1  
> 相关标准库：fmt、os、errors、path/filepath

本篇讲函数的声明与调用：多返回值与命名返回值、可变参数、函数类型与闭包、递归，以及 `defer` 的执行时机。

## 函数声明

函数由关键字 `func`、函数名、参数列表、返回值列表和函数体组成。相邻的同类型参数可以合并书写，`a, b int` 和 `a int, b int` 完全等价：

```go
func add(a, b int) int {
    return a + b
}

fmt.Println(add(1, 2)) // 3
```

函数必须有函数体。只有在配套了汇编文件（或其他语言的实现）时，才可以只写声明、由链接阶段提供实现；在纯 Go 文件里这样写会报 `missing function body`。

Go 也不支持函数重载和参数默认值：同一个包内函数名不能重复，调用时参数个数必须与签名一致。想表达“可选参数”，通常用可变参数、选项结构体，或者函数式选项（把 `func(*Config)` 作为参数传入）。

## 参数：传进去的都是副本

Go 的参数传递都是值传递：传进去的是实参的副本，改参数变量本身不影响调用方。

```go
func change(x int) {
    x = 100
}

n := 1
change(n)
fmt.Println(n) // 1
```

如果参数是切片、map 或指针，函数内部可以通过它们改到底层数据，但参数变量本身仍然是副本——这两件事的区别在 `07-切片.md` 和 `10-指针.md` 里展开。

## 多返回值

Go 函数可以返回多个值，最常见的是返回值加 `error`：

```go
func divmod(a, b int) (int, int) {
    return a / b, a % b
}

quotient, remainder := divmod(7, 3)
fmt.Println(quotient, remainder) // 2 1
```

只关心其中一个时用 `_` 忽略：

```go
func divmod(a, b int) (int, int) {
    return a / b, a % b
}

q, _ := divmod(7, 3)
fmt.Println(q) // 2
```

`(值, error)` 成对返回是 Go 里最常见的多返回值用法，原因见 `05-错误处理.md`。

## 命名返回值

返回值可以命名，函数内部直接给这些变量赋值，最后裸 `return`：

```go
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return
}

fmt.Println(split(9)) // 4 5
```

裸返回适合短函数；函数体长时建议显式写出返回值，便于阅读。

命名返回值还有一个实际用途：**它就是一个普通变量，`defer` 能改它**。这是 `defer` 的机制（见后文「`defer`：注册时求值，返回时才执行」）落到返回值上的结果——把关闭文件时的错误并进返回值，就靠这一手：

```go
func writeConfig(path string, data []byte) (err error) {
    f, err := os.Create(path)
    if err != nil {
        return err
    }

    defer func() {
        err = errors.Join(err, f.Close()) // 把 Close 的错误并进返回值
    }()

    _, err = f.Write(data)

    return err
}

path := filepath.Join(os.TempDir(), "handbook-config.json")
fmt.Println(writeConfig(path, []byte("port=8080"))) // <nil>

data, err := os.ReadFile(path)
fmt.Println(string(data), err) // port=8080 <nil>
```

写入或关闭任何一步出错，调用方拿到的都是合并后的错误。`defer` 与错误的配合、`errors.Join` 的用法见 `05-错误处理.md`。

## 可变参数

最后一个参数写成可变参数后，调用时可以传任意多个值，也可以展开一个切片：

```go
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

fmt.Println(sum(1, 2, 3)) // 6

nums := []int{4, 5, 6}
fmt.Println(sum(nums...)) // 15
```

可变参数在函数内部就是切片类型（`nums` 的类型是 `[]int`），所以传切片时必须加 `...`，否则类型对不上。

## 函数类型与函数值

函数是一等值：可以赋给变量、当参数、当返回值。

```go
func add(a, b int) int {
    return a + b
}

var f func(int, int) int = add

fmt.Println(f(1, 2)) // 3
```

函数类型只看参数和返回值，`func(int, int) int` 与 `func(int) int` 是两个不同的类型：

```go
func add(a, b int) int {
    return a + b
}

func apply(a, b int, op func(int, int) int) int {
    return op(a, b)
}

fmt.Println(apply(1, 2, add)) // 3
```

## 匿名函数与闭包

匿名函数没有名字，可以直接调用：

```go
msg := func() string {
    return "hello"
}()

fmt.Println(len(msg), msg) // 5 hello
```

也可以赋给变量，再当作普通函数用：

```go
greet := func(name string) string {
    return "hello " + name
}

fmt.Println(greet("gopher"))      // 打印 hello gopher
fmt.Println(len(greet("gopher"))) // 12
```

函数可以捕获外部变量，形成闭包：

```go
func counter() func() int {
    n := 0
    return func() int {
        n++
        return n
    }
}

c := counter()
fmt.Println(c()) // 1
fmt.Println(c()) // 2
```

每次调用 `counter` 都会创建独立的 `n`，所以不同闭包之间互不影响——这份状态活在函数里，外面拿不到。

## 递归

```go
func factorial(n int) int {
    if n <= 1 {
        return 1
    }
    return n * factorial(n-1)
}

fmt.Println(factorial(5)) // 120
```

递归适合树形结构、分治和回溯这些问题。写递归时先确认终止条件：条件写错的后果是栈溢出（`stack overflow`），而不是返回一个错值。递归深度很大时，还要留意栈空间和调用开销。

## defer：注册时求值，返回时才执行

`defer` 把函数调用推迟到当前函数返回前执行，多个 `defer` 后进先出。下面的例子用切片把顺序记下来，数字比打印顺序更好对齐（返回值得写成命名返回值，否则 `return out` 已经复制走了切片头，`defer` 里的 append 改不到它）：

```go
func demo() (out []int) {
    defer func() { out = append(out, 1) }()
    defer func() { out = append(out, 2) }()
    out = append(out, 3)

    return
}

fmt.Println(demo()) // [3 2 1]
```

注意 `defer` 后面那个调用**怎么写**也会影响结果，关键看被推迟的到底是"参数"还是"函数体"：

```go
type captureState struct {
    x, got int
}

func capture() (v captureState) {
    c := captureState{x: 1}

    defer fmt.Println(c.x) // 参数在 defer 语句执行时立刻求值：1
    defer func() {
        v.got = c.x // 函数体在返回前才跑，读到那一刻的 c.x：3
    }()
    c.x = 3

    return c
}

fmt.Println(capture()) // 1
// 3 3
```

第一行打印 `1`：`fmt.Println(c.x)` 的参数在 `defer` 语句**执行时**就求值完了，之后 `c.x = 3` 改的已经不是它。第二行里的 `3` 来自 `v.got = c.x`：`func(){}` 是闭包，闭包里读的 `c` 是变量本身，而这段函数体要等到**返回前**才跑，所以读到的是改过之后的 `3`（这里顺便用上了命名返回值能被 `defer` 改这一点，普通返回值不行）。两种写法的差别就在"参数"和"函数体"上，别在 `defer` 里读"注册时以为已经定下来"的值。

`defer` 最常见的用途是关闭资源和释放锁，写法固定成"拿到资源后立刻 defer"：

```go
f, err := os.Open(path)
if err != nil {
    return err
}
defer f.Close() // 无论后面从哪一条路径返回，都会执行
```

### 循环里的 defer：文件会被一直占着

`defer` 注册的调用要等到**函数**返回时才执行，不是循环体结束时。所以把 `defer` 写在循环里会让调用不断堆积：

```go
for _, name := range names {
    f, err := os.Open(name)
    if err != nil {
        return err
    }

    defer f.Close() // 直到整个函数返回才关闭，文件描述符会一直被占着
}
```

需要每次迭代就释放资源时，把循环体抽成一个函数，让 `defer` 随这个函数返回而生效：

```go
func readAll(names []string) error {
    for _, name := range names {
        if err := readOne(name); err != nil {
            return err
        }
    }

    return nil
}

func readOne(name string) error {
    f, err := os.Open(name)
    if err != nil {
        return err
    }

    defer f.Close()

    // 处理 f，函数返回时 f 就会被关闭
    return nil
}
```
