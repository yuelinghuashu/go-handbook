# 02 表达式与运算符

> Go 版本：>= 1.27.1  
> 相关标准库：math、math/cmplx、strconv

运算符的优先级、整除与取模的符号、位运算与移位的边界，以及哪些写法在 Go 里根本不存在，是这一篇要解决的事；内建函数的完整清单（`len`、`make`、`new`、`complex`、`min`/`max` 等）见文末“内建函数”一节。

## 表达式与操作数

表达式由操作数和运算符组成。操作数可以是字面量、变量、常量、函数调用等。

```go
x := 1 + 2
y := x * 3
```

Go 是强类型语言，二元运算符两侧的操作数通常必须具有相同类型。

```go
var i int = 1
var f float64 = 2.5

fmt.Println(i + f) // 编译错误
fmt.Println(float64(i) + f)
```

例外是无类型常量：两侧类型不一致时，无类型的那一侧按上下文补齐类型（规则见 `01-变量与基础类型.md` 的“无类型常量”一节）：

```go
const size = 10

fmt.Println(size + 1)   // 11，int
fmt.Println(size + 1.5) // 11.5，float64
```

## 算术运算符

Go 支持 `+`、`-`、`*`、`/`、`%` 五个算术运算符。它们只作用于数值类型。

```go
a := 7
b := 3

fmt.Println(a + b) // 10
fmt.Println(a - b) // 4
fmt.Println(a * b) // 21
fmt.Println(a / b) // 2
fmt.Println(a % b) // 1
```

整数除法会截断小数部分：

```go
fmt.Println(5 / 2)   // 2
fmt.Println(5.0 / 2) // 2.5
```

`%` 只适用于整数。浮点数取余可以使用 `math.Mod`：

```go
var x float64 = 5.5

fmt.Println(math.Mod(x, 2)) // 1.5
```

整数除法的除数为变量且为零时会在运行时 panic：

```go
a := 0
fmt.Println(1 / a) // panic: integer divide by zero
```

如果除数是常量零，则无法通过编译：

```go
fmt.Println(1 / 0)
```

浮点变量作除数时不会因为为零而 panic，结果可能是 `+Inf` 或 `NaN`。

整数溢出会按补码规则回绕，不会 panic：

```go
var x int8 = 127
x++
fmt.Println(x) // -128
```

除法与取模遇到**负数**时：整数除法向零取整，取模结果的符号跟随**被除数**（不是除数）：

```go
fmt.Println(-7/2, -7%2, 7/-2, 7%-2) // -3 -1 -3 1
```

`math.Mod` 与 `%` 对整数的行为一致，但 `math.Remainder` 是 IEEE 754 的取余（结果符号跟随被减数一侧，绝对值不超过除数的一半），两者在负数上结果不同：

```go
fmt.Println(math.Mod(-7, 2), math.Remainder(-7, 2)) // -1 1
```

无符号整数同样会回绕，只是方向相反——`0` 再减 `1` 变成该类型的最大值：

```go
var u uint8
u--
fmt.Println(u) // 255
```

### 复数运算

复数支持 `+`、`-`、`*`、`/` 四个运算符，类型是 `complex64`/`complex128`（见 `01-变量与基础类型.md` 的“复数类型”一节）。用内建函数 `complex` 构造，`real`/`imag` 取实部虚部：

```go
c := complex(1, 2)

fmt.Println(c, real(c), imag(c), c*c) // (1+2i) 1 2 (-3+4i)
```

字面量 `1 + 2i` 就是普通的常量表达式，乘除优先级照旧：

```go
fmt.Println(1 + 2i*3) // (1+6i)
```

复数的绝对值（模）用 `math/cmplx` 包的 `cmplx.Abs`：

```go
fmt.Println(cmplx.Abs(3 + 4i)) // 5
```

复数只支持相等比较，**没有大小顺序**：

```go
fmt.Println(complex(1, 2) == complex(1, 2)) // true
```

```go
fmt.Println(1i < 2i) // 编译错误：invalid operation: 1i < 2i
```

### 字符串拼接

`+` 除了做加法，也是字符串的拼接运算符，前提是两侧都是 `string`：

```go
fmt.Println("go" + "lang") // golang
```

`+=` 可以追加：

```go
s := "go"
s += "lang"
fmt.Println(s) // golang
```

字符串与其他类型不能直接用 `+`，必须显式转换：

```go
age := 3
fmt.Println("age=" + strconv.Itoa(age)) // age=3
fmt.Println(fmt.Sprintf("age=%d", age)) // age=3
```

字符串是不可变的，不能通过索引赋值：

```go
s := "go"
// s[0] = 'G' // 编译错误：cannot assign to s[0]
```

在循环里反复 `+=` 会不停地分配新字符串，拼接量大时应改用 `strings.Builder`，具体见 `20-字符串与字节.md`。

## 比较运算符

比较运算符的结果是 `bool`：

```go
fmt.Println(1 == 1) // true
fmt.Println(1 != 2) // true
fmt.Println(1 < 2)  // true
fmt.Println(2 <= 2) // true
fmt.Println(3 > 2)  // true
fmt.Println(3 >= 4) // false
```

数字和字符串支持顺序比较，字符串按**字节**顺序比较：

```go
fmt.Println("a" < "b") // true
```

字节序不等于"人读的顺序"：`"Z" < "a"` 也是 `true`（大写字母的字节值更小），非 ASCII 文本的先后更与语言习惯无关——字符串的字节视图见 `20-字符串与字节.md`。

布尔值只能使用 `==` 和 `!=`，不能使用 `<`、`>` 等顺序比较。

切片、map 和函数只能和 `nil` 比较：

```go
var s []int
fmt.Println(s == nil) // true
```

结构体和数组是否可比较，取决于它们的元素是否可比较。

## 逻辑运算符

逻辑运算符用于布尔值：

```go
fmt.Println(true && false) // false
fmt.Println(true || false) // true
fmt.Println(!true)         // false
```

`&&` 和 `||` 具有短路特性。`false && x` 不会计算 `x`，`true || x` 也不会计算 `x`：

```go
func sideEffect() bool {
    fmt.Println("called")
    return true
}

fmt.Println(false && sideEffect())
fmt.Println(true || sideEffect())
```

两段输出都不会打印 `called`，因为右侧表达式没有被求值。

布尔值**没有位运算形式**：`&`、`|`、`^` 只作用于整数，布尔只有 `&&`、`||`、`!` 三个运算符，所以别想用 `&` 来"不求值地按位与"：

```go
fmt.Println(true & false) // 编译错误：invalid operation: operator & not defined on true
```

`&&` 的优先级高于 `||`：

```go
fmt.Println(true || false && false) // true
```

## 位运算符

位运算符用于整数：

```go
a := 6 // 0110
b := 3 // 0011

fmt.Println(a & b)  // 2
fmt.Println(a | b)  // 7
fmt.Println(a ^ b)  // 5
fmt.Println(a &^ b) // 4
```

`&^` 是位清除，表示把 `a` 中 `b` 为 `1` 的位清零。

移位运算：

```go
fmt.Println(1 << 3) // 8
fmt.Println(8 >> 2) // 2
```

`^` 作为一元运算符时表示按位取反：

```go
fmt.Println(^5) // -6
```

`>>` 对**有符号负数**是算术移位（补 1），对无符号数才是逻辑移位（补 0）：

```go
var neg int8 = -8

fmt.Println(neg>>1, neg>>7) // -4 -1
```

**下面这几条是移位的边界行为，属于"知道有这回事"的层次，初读可以跳过**——日常写位运算很少踩到，需要时回来查即可。

移位次数是**运行时变量**时，超过位宽不会被拒绝，结果是 0（有符号负数右移则是全 1）；但次数为负会直接 panic：

```go
var b uint8 = 1
var cnt uint = 8

fmt.Println(b<<cnt, b<<(cnt-1), b>>7) // 0 128 0
```

```go
var cnt = -1

fmt.Println(1 << cnt) // panic: runtime error: negative shift amount
```

移位次数是**常量**时，越界在编译期就被拦下：

```go
fmt.Println(int8(1) << 8) // 编译错误：int8(1) << 8 (constant 256 of type int8) overflows int8
```

## 赋值运算符

普通赋值使用 `=`：

```go
x := 1
x = 2
```

复合赋值运算符可以简化运算和赋值：

```go
x := 10

x += 5 // x = x + 5
x -= 3 // x = x - 3
x *= 2 // x = x * 2
x /= 4 // x = x / 4
x %= 4 // x = x % 4
```

位运算和移位也有对应的复合赋值：

```go
x := 6

x &= 3  // x = x & 3
x |= 4  // x = x | 4
x ^= 2  // x = x ^ 2
x &^= 1 // x = x &^ 1
x <<= 1 // x = x << 1
x >>= 1 // x = x >> 1
```

赋值左侧可以有多个变量。Go 会先算完右边的全部表达式，再同时赋给左边，所以交换两个值不需要临时变量：

```go
a, b := 1, 2

a, b = b, a
fmt.Println(a, b) // 2 1
```

`++` 和 `--` 是语句，不是表达式：

```go
x := 1
x++
fmt.Println(x) // 2

// y := x++ // 非法
```

## 一元运算符

一元运算符只有一个操作数，优先级高于所有二元运算符。Go 里一共有七个：

| 运算符      | 作用                     | 详细内容         |
| ----------- | ------------------------ | ---------------- |
| `+x` / `-x` | 取正 / 取负              | 本节             |
| `!x`        | 布尔取反                 | 本节             |
| `^x`        | 按位取反，**不是幂运算** | 上文"位运算符"   |
| `*p`        | 解引用指针               | `10-指针.md`     |
| `&x`        | 取地址                   | `10-指针.md`     |
| `<-ch`      | 从 channel 接收          | `38-并发基础.md` |

求幂用 `math.Pow`，Go 里没有幂运算符：

```go
fmt.Println(-3, +3, !true, ^5) // -3 3 false -6
```

还有三个"别的语言有、Go 没有"的运算符，写代码时容易顺手写错：

- **没有三目运算符 `?:`**：条件分支用 `if`/`else` 语句，取最值用 `min`/`max`（见下文"内建函数"）。
- **没有指针算术**：`p + 1` 不合法，遍历数组用下标或 `range`（见 `10-指针.md`）。
- **运算符不能重载**：自定义类型无法定义 `+`、`==` 的含义，需要这类行为就写方法（见 `11-方法.md`）。

## 运算符优先级

Go 的二元运算符优先级从高到低如下：

```text
5: *  /  %  <<  >>  &  &^
4: +  -  |  ^
3: ==  !=  <  <=  >  >=
2: &&
1: ||
```

同级运算符从左到右结合。一元运算符 `+`、`-`、`!`、`^`、`*`、`&`、`<-` 的优先级高于二元运算符。

当表达式比较复杂时，建议使用括号明确计算顺序：

```go
a, b, c := 1, 2, 3

result := (a + b) * c // 先加后乘，结果为 9
fmt.Println(result)
```

## 内建函数

`len`、`append`、`make` 这些名字不需要导入、也不属于任何包，它们是**预声明的内建函数**。`go doc builtin` 列出的全部 18 个如下（"详细内容"一栏是它们的主场）：

| 内建函数                                | 作用                                                                            | 详细内容                                    |
| --------------------------------------- | ------------------------------------------------------------------------------- | ------------------------------------------- |
| `len(v)`                                | 长度：字符串是字节数，数组/切片是元素数，map 是元素数，channel 是缓冲区中元素数 | 本节                                        |
| `cap(v)`                                | 容量：数组、切片、channel；**不能用于字符串**                                   | 本节                                        |
| `append(s, …)`                          | 追加元素，必要时扩容                                                            | `07-切片.md`                                |
| `copy(dst, src)`                        | 复制元素，返回复制的个数                                                        | `07-切片.md`                                |
| `make(T, …)`                            | 创建并初始化切片、map、channel                                                  | `07-切片.md`、`08-map.md`、`38-并发基础.md` |
| `new(T)` / `new(expr)`                  | 分配零值并返回指针                                                              | `10-指针.md`                                |
| `delete(m, k)`                          | 删除 map 的键                                                                   | `08-map.md`                                 |
| `clear(v)`                              | 清空 map，或把切片元素全部置零（Go 1.21 起）                                    | `08-map.md`、`07-切片.md`                   |
| `close(ch)`                             | 关闭 channel                                                                    | `38-并发基础.md`                            |
| `min(…)` / `max(…)`                     | 一组有序值里的最小 / 最大值（Go 1.21 起）                                       | 本节                                        |
| `panic(v)` / `recover()`                | 抛出 / 接住 panic                                                               | `05-错误处理.md`                            |
| `complex(r, i)` / `real(c)` / `imag(c)` | 构造复数、取实部虚部                                                            | 上文"复数运算"                              |
| `print(…)` / `println(…)`               | 写标准**错误**，格式不做保证                                                    | 本节                                        |

还有几个预声明标识符容易和内建函数混在一起：常量 `true`、`false`、`iota`、`nil`（见 `01-变量与基础类型.md`），以及类型别名 `any`、`byte`、`rune`、`comparable`、`error`（见 `12-接口.md`、`13-泛型与类型系统.md`）。

### len 和 cap

`len` 能用在五种形态上，含义各不相同——**字符串上它是字节数，不是字符数**：

```go
fmt.Println(len("Go语言"), len([]rune("Go语言"))) // 8 4
fmt.Println(len(map[string]int{"a": 1, "b": 2}))  // 2
fmt.Println(len([]int{0, 0}))                     // 2
```

`cap` 只接受数组、切片和 channel（数组指针也行），用在字符串上是编译错误：

```go
var s string

fmt.Println(cap(s)) // 编译错误：invalid argument: s (variable of type string) for built-in cap
```

channel 的 `len` 是缓冲区里**当前排队**的元素个数，`cap` 是缓冲区大小：

```go
ch := make(chan int, 3)

fmt.Println(len(ch), cap(ch)) // 0 3
```

数组指针同样能取长度和容量，`p := &[4]int{}` 时 `len(p)`、`cap(p)` 都是 `4`。

`len` 的参数是**字符串常量**时，结果本身也是常量，可以直接参与常量声明和常量运算：

```go
const n = len("abc")

fmt.Println(n, n*2) // 3 6
```

### print 和 println

`print`/`println` 是给运行时和调试用的：它们**写标准错误**（不是标准输出）、输出格式不做保证、随版本可能变化。生产代码一律用 `fmt`：

```go
println("hello", 42) // 写到 stderr，格式不保证
```

### 内建函数不能当值用

内建函数不是一等公民：不能赋值给变量、不能当参数传递，只能直接调用：

```go
f := len // 编译错误：len (built-in) must be called
```

要把"取长度"这类操作传给别的代码，得自己包一层函数，或用泛型约束表达（见 `13-泛型与类型系统.md`）。

### min 和 max

Go 1.21 起提供了 `min`、`max` 两个内建函数，支持所有有序类型（整数、浮点、字符串）：

```go
fmt.Println(min(3, 1, 2)) // 1
fmt.Println(max(3, 1, 2)) // 3
```

它们是**内建函数而不是运算符**，所以没有优先级问题，也不参与上面那张优先级表。参数个数可以是任意多个（至少一个），返回值类型与参数一致——整数取最值不用先转成 `float64`，这一点是它比 `math.Min`/`math.Max` 方便的地方（见 `25-数学与随机数.md`）。

无类型常量会按上下文自动适配，所以混着写也能用；但两侧都已经定型且类型不同就会报错：

```go
fmt.Println(min(1, 2.5), min(1, int8(2))) // 1 1
```

```go
fmt.Println(min(int8(1), int(2))) // 编译错误：invalid argument: mismatched types int8 and int
```

同一批引入的还有 `clear`，它作用于 map 和切片，属于容器操作，分别在 `08-map.md` 的"删除与清空"和 `07-切片.md` 的"clear"两节里讲。
