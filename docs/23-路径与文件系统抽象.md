# 23 路径与文件系统抽象

> Go 版本：>= 1.27.1  
> 相关标准库：io/fs、path、path/filepath、embed

`22-文件与目录操作.md` 那一套直接操作真实磁盘。这一篇换个角度：把文件系统当成**接口**看——同一段代码可以跑在磁盘目录（`os.DirFS`）、内存里的假文件系统（`fstest.MapFS`）或者嵌进二进制的目录树（`embed.FS`）上；路径处理则要分清 `path`（永远用 `/`）和 `filepath`（跟平台的分隔符）。

## io/fs

`io/fs` 定义了文件系统的抽象：

```go
type FS interface {
    Open(name string) (fs.File, error)
}
```

（这里写成 `fs.File`；标准库文档里的 `File` 是同一个类型在包 fs 内部的写法。）

下面几个例子用一个内存文件系统 `fstest.MapFS` 当素材（标准库 `testing/fstest` 里的实现），这样不必先在磁盘上造目录；把 `fsys` 换成 `os.DirFS(dir)`，就是同一套代码跑在真实目录上。

读取文件：

```go
fsys := fstest.MapFS{
    "config.json": &fstest.MapFile{Data: []byte(`{"port":8080}`)},
}

data, err := fs.ReadFile(fsys, "config.json")
if err != nil {
    log.Fatal(fmt.Errorf("read config.json: %w", err))
}

fmt.Printf("%s\n", data) // {"port":8080}
```

遍历目录：

```go
func collectPaths(fsys fs.FS) ([]string, error) {
    var paths []string
    err := fs.WalkDir(fsys, ".", func(path string, d fs.DirEntry, err error) error {
        if err != nil {
            return fmt.Errorf("walk %s: %w", path, err)
        }

        paths = append(paths, path)
        return nil
    })
    if err != nil {
        return nil, fmt.Errorf("walk: %w", err)
    }
    return paths, nil
}

fsys := fstest.MapFS{
    "a.txt":     &fstest.MapFile{Data: []byte("A")},
    "sub/b.txt": &fstest.MapFile{Data: []byte("B")},
}

paths, err := collectPaths(fsys)
if err != nil {
    log.Fatal(err)
}

fmt.Printf("%q\n", paths) // ["." "a.txt" "sub" "sub/b.txt"]
```

`os.DirFS(".")` 可以把某个目录包装成 `fs.FS`：

```go
fsys := os.DirFS(".") // 当前目录

entries, err := fs.ReadDir(fsys, ".")
if err != nil {
    log.Fatal(fmt.Errorf("read dir: %w", err))
}

fmt.Println(len(entries) > 0) // true：fs 那一套函数现在读的是真实目录
```

`fs.WalkDir` 和 `filepath.WalkDir` 都是**按字典序**遍历的：输出确定可复现，代价是要先把整个目录读进内存再往下走。`fs.WalkDir` 传给你的路径始终用 `/` 分隔，`filepath.WalkDir` 用当前系统的分隔符。

### fs.Sub、fs.Glob、fs.ValidPath

`fs.Sub` 把某个子树当成一个新的 `fs.FS`（只是路径前缀映射，**不会检查该目录是否存在**）：

```go
fsys := fstest.MapFS{
    "conf/app.json": &fstest.MapFile{Data: []byte(`{"port":8080}`)},
}

sub, err := fs.Sub(fsys, "conf")
if err != nil {
    log.Fatal(fmt.Errorf("sub conf: %w", err))
}

data, err := fs.ReadFile(sub, "app.json") // 实际读取 conf/app.json
if err != nil {
    log.Fatal(fmt.Errorf("read app.json: %w", err))
}

fmt.Printf("%s\n", data) // {"port":8080}

// 目录不存在时 Sub 照样返回成功，错误要到真正读文件时才出现
missing, err := fs.Sub(fsys, "nope")
if err != nil {
    log.Fatal(fmt.Errorf("sub nope: %w", err))
}

_, err = fs.ReadFile(missing, "app.json")

fmt.Println(errors.Is(err, fs.ErrNotExist)) // true
```

注意 `fs.Sub` 和 `os.DirFS` **都不是安全边界**：它们不阻止符号链接跳出前缀。要真正限制访问范围请用 `os.Root`（见 `22-文件与目录操作.md` 的"os.Root"一节）。

`fs.Glob` 用 `path.Match` 的语法在 `fs.FS` 上做模式匹配，结果按字典序（每个目录内的条目来自排好序的 `fs.ReadDir`）；唯一的返回错误是模式非法的 `path.ErrBadPattern`，目录读写错误会被静默忽略：

```go
fsys := fstest.MapFS{
    "a.json": &fstest.MapFile{Data: []byte("A")},
    "b.json": &fstest.MapFile{Data: []byte("B")},
    "c.txt":  &fstest.MapFile{Data: []byte("C")},
}

matches, err := fs.Glob(fsys, "*.json")
if err != nil {
    log.Fatal(fmt.Errorf("glob *.json: %w", err))
}

fmt.Printf("%q\n", matches) // ["a.json" "b.json"]
```

`*` 不跨越 `/`，要匹配下一层得写 `*/*.json`；`**` 没有特殊含义，效果和 `*` 一样。

`fs.ValidPath` 判断一个名字是否是合法的 `fs.FS` 路径（始终用 `/`、不能为空、不能以 `/` 开头、不能含 `.` 或 `..` 元素，`.` 本身合法）：

```go
fmt.Println(fs.ValidPath("a/b"))  // true
fmt.Println(fs.ValidPath("."))    // true
fmt.Println(fs.ValidPath("./a"))  // false
fmt.Println(fs.ValidPath("../a")) // false
fmt.Println(fs.ValidPath("/a"))   // false
```

### 控制遍历：fs.SkipDir 与 fs.SkipAll

遍历回调返回两个特殊值可以提前收手，它们**不会**被当作错误返回：

```go
func collectSkipping(fsys fs.FS) ([]string, error) {
    var paths []string
    err := fs.WalkDir(fsys, ".", func(path string, d fs.DirEntry, err error) error {
        if err != nil {
            return fmt.Errorf("walk %s: %w", path, err)
        }

        if d.IsDir() && d.Name() == "testdata" {
            return fs.SkipDir // 当前是目录：不进入它
        }

        paths = append(paths, path)
        return nil
    })
    if err != nil {
        return nil, fmt.Errorf("walk: %w", err)
    }
    return paths, nil
}

fsys := fstest.MapFS{
    "a.txt":           &fstest.MapFile{Data: []byte("A")},
    "testdata/b.json": &fstest.MapFile{Data: []byte("B")},
}

paths, err := collectSkipping(fsys)
if err != nil {
    log.Fatal(err)
}

fmt.Printf("%q\n", paths) // ["." "a.txt"]：testdata 整个被跳过了
```

- `fs.SkipDir`：`d.IsDir()` 为真时跳过该目录（不进入），否则跳过该路径**所在目录**中剩余的文件。
- `fs.SkipAll`：终止整棵树的遍历，`WalkDir` 返回 `nil`。

```go
func collectUntil(fsys fs.FS, name string) ([]string, error) {
    var paths []string
    err := fs.WalkDir(fsys, ".", func(path string, d fs.DirEntry, err error) error {
        if err != nil {
            return fmt.Errorf("walk %s: %w", path, err)
        }

        paths = append(paths, path)
        if d.Name() == name {
            return fs.SkipAll // 整棵树到此为止
        }
        return nil
    })
    if err != nil {
        return nil, fmt.Errorf("walk: %w", err)
    }
    return paths, nil
}

fsys := fstest.MapFS{
    "a.txt": &fstest.MapFile{Data: []byte("A")},
    "b.txt": &fstest.MapFile{Data: []byte("B")},
}

paths, err := collectUntil(fsys, "b.txt")
if err != nil {
    log.Fatal(err)
}

fmt.Printf("%q\n", paths) // ["." "a.txt" "b.txt"]：走到 b.txt 就停了，字典序里它后面的条目不会再访问
```

## path 与 filepath

路径处理有两个包，区别只在于分隔符：`path` 永远用 `/`，适合 URL 或统一格式的路径；`filepath` 用当前操作系统的分隔符（Windows 上是 `\`），适合本地文件。

```go
// Join：用 / 拼接；Base：最后一段；Dir：去掉最后一段；Ext：扩展名（含点）
fmt.Printf("%q\n", path.Join("a", "b", "c")) // "a/b/c"
fmt.Printf("%q\n", path.Base("a/b/c.txt"))   // "c.txt"
fmt.Printf("%q\n", path.Dir("a/b/c.txt"))    // "a/b"
fmt.Printf("%q\n", path.Ext("a/b/c.txt"))    // ".txt"
```

```go
// filepath 与 path 同名同义，只是换成平台分隔符：Windows 上 Join 出来是 data\config.json
p := filepath.Join("data", "config.json")

fmt.Printf("%q\n", filepath.ToSlash(p))                  // "data/config.json"：ToSlash 统一成 /
fmt.Println(p == filepath.FromSlash("data/config.json")) // true：两种写法指同一个路径

fmt.Printf("%q\n", filepath.Base("a/b/c.txt"))                      // "c.txt"
fmt.Println(filepath.Dir("a/b/c.txt") == filepath.FromSlash("a/b")) // true
fmt.Printf("%q\n", filepath.Ext("a/b/c.txt"))                       // ".txt"

// Clean：消掉 . 和 ..、合并重复分隔符，纯词法处理、不碰文件系统
fmt.Printf("%q\n", filepath.Clean("a/../b")) // "b"

// IsLocal：用户给的相对路径安不安全（不带 ..、不是绝对路径）
fmt.Println(filepath.IsLocal("a/b"), filepath.IsLocal("../a"), filepath.IsLocal("/a")) // true false false

// Abs 基于当前工作目录拼绝对路径，它也会返回 error
abs, err := filepath.Abs("data")
if err != nil {
    log.Fatal(fmt.Errorf("abs data: %w", err))
}

fmt.Println(filepath.IsAbs(abs)) // true

// Glob 读目录失败时会返回错误；结果本身随工作目录变化，所以这里只检查错误
if _, err := filepath.Glob("*.go"); err != nil {
    log.Fatal(fmt.Errorf("glob *.go: %w", err))
}
```

判断用户提供的路径是否安全（不带 `..`、不是绝对路径）用 `filepath.IsLocal`（Go 1.20 起）；要遍历本地目录用 `filepath.WalkDir`（路径带平台分隔符），要真正限制在一个目录内用 `os.Root`（见 `22-文件与目录操作.md` 的"os.Root"一节）。

## embed

`embed` 用于把文件嵌入到二进制中。下面三段是**文件级摘录**：`import` 行与 `//go:embed` 指向的文件都必须在真实的包里存在（编译器在构建时就要找到 `config.json`、`templates/`），所以它们不参与本篇的自动输出校验，照抄时要连同 `import` 一起放进文件。

```go
import _ "embed"

//go:embed config.json
var configData []byte
```

只嵌入 `string` 或 `[]byte` 时使用空白导入；如果变量类型是 `embed.FS`，则需要普通导入 `"embed"`。

嵌入整个目录：

```go
import "embed"

//go:embed templates/*
var templates embed.FS
```

读取嵌入文件（`templates` 就是上面那个 `embed.FS`）：

```go
data, err := templates.ReadFile("templates/index.html")
if err != nil {
    log.Fatal(fmt.Errorf("read templates/index.html: %w", err))
}

fmt.Println(string(data))
```

`go:embed` 指令必须紧跟在变量声明之前，变量类型只能是 `string`、`[]byte` 或 `embed.FS`。`embed.FS` 实现的就是本篇开头那个 `fs.FS`，所以模板、静态资源都能用同一套 `fs` 函数读（见 `36-优先队列与模板.md` 的"模板多了以后：从文件与 fs.FS 加载"一节）。
