# 01 变量与基础类型

> Go 版本：>= 1.27.1  
> 相关标准库：fmt、strconv

读之前先知道四条，**全系列的示例都按这几条约定写**：

- 示例统一用 `fmt.Println` / `fmt.Printf` 打印结果，这两个函数和格式动词的用法集中在文末"输出与格式化"一节，先照着用即可。
- 需要完整程序时，代码会放在 `func main() { ... }` 里——函数本身的语法见 `04-函数.md`。
- **片段里出现裸 `return err` / `return nil` 时，表示这段代码是写在"你自己的、返回 `error` 的函数"里的**，不是 `func main()`。文档里很多示例会省略外层函数，只留下与讲解相关的那几行。
- 本篇只讲"声明与类型"：控制流的语法见 `03-控制流.md`，指针见 `10-指针.md`，字符串的处理（`strings`/`strconv`/UTF-8）见 `20-字符串与字节.md`。

## 变量声明

Go 是静态强类型语言。变量必须先声明后使用，声明后的类型通常不再改变。最基础的声明方式是 `var`。

```go
var a int
var b string
var c bool
```

`var` 也可以根据右侧表达式推断类型：

```go
var count = 10       // int
var price = 19.9     // float64
var name = "gopher"  // string
var ok = true        // bool
```

一次声明多个变量：

```go
var x, y = 1, 2
var title, author string
```

需要声明一组相关变量时，可以使用括号：

```go
var (
    host  string
    port  int
    debug bool
)
```

包级别和函数内部都可以使用 `var`，但 `var` 后面必须给出类型或初始值。像 `var x` 这样既没有类型也没有初始值的写法，在包级和函数内都会报语法错误，并不是只限制包级变量。

## 短变量声明

函数内部可以使用 `:=`：

```go
func main() {
    message := "hello"
    count := 3
    fmt.Println(message, count)
}
```

`:=` 会自动推断类型。下面 `n` 是 `int`，`ratio` 是 `float64`：

```go
n := 10
ratio := 0.5
```

也可以在一条语句里声明多个变量：

```go
x, y := 1, 2
```

短变量声明要求左侧至少有一个新变量。如果一个变量已经在同一作用域中存在，再次使用 `:=` 时必须有新变量加入：

```go
a, b := 1, 2
a, c := 3, 4 // 合法：c 是新变量
```

下面这行无法通过编译，因为没有引入新变量：

```go
a, b := 1, 2
a, b := 3, 4
```

`:=` 只能出现在函数内部，包级变量必须用 `var`、`const` 或 `type` 声明。包级别这样写无法通过编译：

```go
// package main
//
// x := 1 // 编译错误：expected declaration, found x
```

## 零值

Go 中声明变量但不显式初始化时，变量会获得该类型的零值。

```go
var (
    n     int
    f     float64
    s     string
    ok    bool
    p     *int
    list  []int
    table map[string]int
)
```

对应的零值分别是：

- 数值类型：`0`
- `float32`、`float64`：`0`
- `bool`：`false`
- `string`：空字符串
- 指针、切片、map、channel、函数、接口：`nil`
- 结构体：每个字段都是对应类型的零值
- 数组：每个元素都是对应类型的零值

可以直接打印观察：

```go
fmt.Printf("%v %v %v %v %v %v %v", n, f, s, ok, p, list, table)
```

输出：

```text
0 0  false <nil> [] map[]
```

`nil` 是预声明的标识符，不是类型。同样是 `nil`，不同类型的可用程度并不一样：切片可以直接 `append`；map 必须先 `make`，往 nil map 里赋值会直接 panic；channel 也是 nil 上收发会永久阻塞，必须 `make` 之后才能正常通信（map 的完整规则见 `08-map.md` 的“map 的零值语义”一节，channel 的见 `38-并发基础.md`）。

## 常量与 iota

常量使用 `const` 声明，值必须在编译期确定：

```go
const Pi = 3.14159
const Greeting = "hello"
```

一次声明多个常量：

```go
const (
    StatusOK       = 200
    StatusNotFound = 404
)
```

常量只能声明，不能用 `:=`（`:=` 的规则见上文“短变量声明”一节）。下面写法是非法的：

```go
// const x := 1 // 编译错误：expected ';', found ':='
```

### 无类型常量

常量可以是无类型的，使用时会根据上下文取合适类型：

```go
const size = 10

var i int = size
var f float64 = size
```

`const` 的值在**编译期**求值，无类型常量自身是**任意精度的精确值**（规范原文：Numeric constants represent exact values of arbitrary precision），不受目标类型范围限制：落到整型上必须能精确表示（`var i int8 = 300` 直接编译报错），落到浮点上才取最接近的可表示值。

```go
const huge = 1 << 200 // 远超 int64，但作为常量本身完全合法

fmt.Println(huge >> 190) // 1024，用到的值落在 int 范围内就行
```

不需要上下文提供类型时，无类型常量取自己的**默认类型**，由它的 kind 决定：

| kind               | 默认类型     |
| ------------------ | ------------ |
| 布尔               | `bool`       |
| rune（字符字面量） | `rune`       |
| 整数               | `int`        |
| 浮点               | `float64`    |
| 复数               | `complex128` |
| 字符串             | `string`     |

默认类型最常出场的两处是泛型推断（见 `13-泛型与类型系统.md` 的“无类型常量的默认类型”一节）和 `new(42)` 得到的 `*int`（见 `10-指针.md`）。浮点上这么做的实际后果见下文“浮点类型”。

`iota` 用在常量组中，它有三条规则：

- 每个 `const` 关键字把 `iota` 重置为 `0`，之后每多一行常量声明就加 `1`；空行和注释不计入。
- 省略表达式时，该行复用上一行**完整的表达式列表**，不只是复用 `iota` 这个词。
- `iota` 只能出现在常量声明里。

```go
type Weekday int

const (
    Sunday Weekday = iota // 0
    Monday                // 1，复用上一行的 "Weekday = iota"
    Tuesday               // 2
    Wednesday             // 3
    Thursday              // 4
    Friday                // 5
    Saturday              // 6
)
```

`Sunday` 是 `0`，`Monday` 是 `1`，依次类推。`iota` 也可以参与更复杂的表达式，这时"复用上一行完整表达式"这条规则的作用最明显：

```go
const (
    _  = iota             // 0，用空白标识符占位丢弃
    KB = 1 << (10 * iota) // 1 << 10
    MB                    // 复用上式：1 << (10 * 2)
    GB                    // 复用上式：1 << (10 * 3)
)

const C = iota // 0，新的常量组把 iota 重置为 0
```

这里 `KB`、`MB`、`GB` 分别是 `1 << 10`、`1 << 20`、`1 << 30`：复用的是含 `iota` 的整个表达式，而每一行的 `iota` 取值不同。`const C = iota` 则说明每遇到一个新的 `const` 关键字，`iota` 都会重新从 `0` 开始。

## 作用域与遮蔽

Go 使用词法作用域。内层块可以重新声明外层同名变量，这称为遮蔽：

```go
var message = "outer"

func main() {
    fmt.Println(message) // outer

    message := "inner"
    fmt.Println(message) // inner
}
```

内层块结束后，外层变量仍然存在：

```go
func main() {
    x := 1

    {
        x := 2
        fmt.Println(x) // 2
    }

    fmt.Println(x) // 1
}
```

`if`、`for`、`switch` 也会引入自己的作用域（写在初始化语句里的变量出了这条语句就不可见），具体写法见 `03-控制流.md` 的“作用域”一节。

## 基础类型

Go 的基础类型分为布尔、数值（整数 / 浮点 / 复数）和字符串，另有 `byte`、`rune`、`any` 三个别名。每一类下面连同它的字面量写法一起给出。

### 布尔类型

```go
var ok bool = true
```

布尔值只能是 `true` 或 `false`，不能和整数互转。

### 整数类型

有符号整数：

```text
int  int8  int16  int32  int64
```

无符号整数：

```text
uint  uint8  uint16  uint32  uint64  uintptr
```

`int` 和 `uint` 的宽度取决于平台，通常是 64 位。需要精确宽度时使用 `int32`、`int64` 等类型。

整数可以用四种进制书写，并允许用下划线 `_` 分隔便于阅读：

```go
0b1010     // 10，二进制
0o755      // 493，八进制
0x1f       // 31，十六进制
1_000_000  // 1000000，下划线仅用于分隔，不影响取值
```

下划线可以放在数字之间，**也可以紧跟进制前缀**（`0x_1f`、`0b_1010` 都合法），但不能放在开头、结尾或紧邻小数点。

### 浮点类型

```go
var f32 float32 = 1.5
var f64 float64 = 3.14159
```

字面量可以写成小数、科学计数法或十六进制浮点，小数点两侧都可以省略一边：

```go
1.5
1e9        // 1e+09
.5         // 0.5，整数部分可以省略
1_000.5    // 1000.5
0x1p-2     // 0.25，十六进制浮点：1 × 2⁻²
```

浮点字面量的默认类型是 `float64`。`float64` 只能精确表示有限个十进制小数，浮点运算会带来舍入误差，但**这个误差只有在操作数是 `float64` 值的时候才会出现**：

```go
a, b := 0.1, 0.2

fmt.Println(a + b) // 0.30000000000000004
```

也就是说，这个坑必须用变量才踩得到：字面量 `0.1`、`0.2` 是无类型常量，整个表达式在编译期按精确值算完才转成 `float64`，所以 `fmt.Println(0.1 + 0.2)` 打印的是 `0.3` 而不是 `0.30000000000000004`（见上文“无类型常量”一节）。

需要精确的小数运算用 `math/big`（见 `25-数学与随机数.md` 的“math/big 精确计算”一节）；浮点数的 NaN 不满足任何比较运算，见 `17-cmp.md` 的“NaN 的处理”一节。

### 复数类型

```go
var c64 complex64 = 1 + 2i
var c128 complex128 = 3 + 4i
```

### 字符串类型

Go 的字符串是**不可变的字节序列**（不是字符序列），通常存放 UTF-8 编码的文本：`len` 和下标都按字节走，按字符处理要用 `range`（拿 rune 和字节下标）或 `[]rune`。这些规则背后的机制、非法 UTF-8 的边界情况与完整可运行示例都在 `20-字符串与字节.md` 的“字符串的本质”一节。

字符串字面量有两种写法，区别很大：

```go
s1 := "a\nb"   // 解释型：\n 被转义成换行，长度为 3
s2 := `a\nb`   // 原始型：\n 是反斜杠加 n 两个字面字符，长度为 4
```

反引号包裹的是**原始字符串字面量**：不做任何转义处理，可以跨多行，因此适合写正则、JSON、SQL 和 Shell 片段。

```go
pattern := `^\d{3}-\d{4}$`
query := `
SELECT id, name
FROM users
WHERE age > 18
`
```

原始字符串里不能包含反引号本身；另外其中的回车符 `\r` 会被直接丢掉（换行 `\n` 会保留）。

日常代码里最常需要原始字符串的地方其实是**结构体标签**：标签内容本身就要写双引号，用解释型字符串就得逐个转义（例子见 `09-struct.md` 的“标签”一节）。

反过来说，不需要转义、也不跨行的普通文本（`"hello"`、`"config.json"`）一律用双引号，这是 Go 的书写惯例；只有确实需要原始语义时才用反引号。本笔记后面各篇都遵循这条。

### byte 和 rune

`byte` 是 `uint8` 的别名，表示一个字节；`rune` 是 `int32` 的别名，表示一个 Unicode 码点：

```go
var b byte = 'A'
var r rune = '语'
```

rune 字面量用单引号，写的是一个 Unicode 码点，支持转义：

```go
'A'        // 65
'\n'       // 换行
'\x41'     // 65，十六进制字节
'\101'     // 65，八进制
'\u4e2d'   // 20013，即“中”
```

rune 字面量是**无类型** rune 常量，默认类型是 `rune`（即 `int32`），所以既能赋给 `rune`/`int32`，也能在需要时按其它数值类型使用。`'\x41'`、`'\101'` 与 `'A'` 完全等价。

`string`、`[]byte`、`[]rune` 之间可以相互转换，**转换都会复制一份数据**，热点路径上要留意分配（示例与成本见 `20-字符串与字节.md` 的“字符串与字节切片”一节）。

### any

`any` 是 `interface{}` 的别名，可以指向任意类型的值：`var value any = 42`。空接口能做什么、怎么把值取回来（类型断言、类型 switch）见 `12-接口.md` 的“空接口与 any”一节。

## 类型转换

Go 不允许隐式类型转换。不同类型之间即使看起来兼容，也必须显式转换：

```go
var i int = 10
var f float64 = i        // 编译错误
var g float64 = float64(i) // 正确
```

`g` 到这里已经是 `float64` 了，但打印出来是 `10` 而不是 `10.0`，这是 `%v` 对浮点数的输出规则，不是转换失败（用 `%T` 可以确认类型，原因见下文“常用格式动词”）。

浮点数转整数会截断小数部分：

```go
var f = 3.9
var i = int(f) // 3
```

整数转字符串时要注意语义：

```go
fmt.Println(string(65)) // A
```

这里 `65` 被当作 Unicode 码点。如果想把数字变成文本，应使用 `strconv.Itoa`：

```go
fmt.Println(strconv.Itoa(65)) // 65
```

`strconv` 的完整用法（解析、格式化、进制、浮点、布尔）见 `20-字符串与字节.md` 的“strconv 数字与字符串转换”一节。

## 输出与格式化

`fmt` 既负责输出，也负责生成格式化字符串。按**输出去向**分，打印函数有四个家族（`go doc fmt` 原文：There are four families of printing functions defined by their output destination）：`Print*` 写 `os.Stdout`、`Sprint*` 返回字符串、`Fprint*` 写任意 `io.Writer`、`Append*` 追加到 `[]byte`。此外 `Errorf` 专门用来生成 `error`。

### 输出到标准输出

```go
name := "gopher"
age := 3

fmt.Print(name, age)                    // gopher3 —— 相邻操作数都不是字符串时才自动补空格
fmt.Println(name, age)                  // gopher 3
fmt.Printf("name=%s age=%d", name, age) // name=gopher age=3
```

`Print` 和 `Println` 适合简单调试，`Printf` 适合需要控制格式的场景。

### 生成格式化字符串

`Sprintf` 不直接输出，而是返回字符串：

```go
message := fmt.Sprintf("%s is %d", name, age)
fmt.Println(message) // gopher is 3
```

另外两个家族的落点不在本篇：往 `io.Writer` 写（`Fprintf`）和往 `[]byte` 追加（`Appendf`，热路径里能省一次分配）见 `21-io与流.md`；用 `Errorf` 生成/包装 error 见 `05-错误处理.md`。

### 常用格式动词

不必一次记住全部：日常打印数据用 `%v`（结构体配 `%+v`），调试类型用 `%T`，数字用 `%d`、字符串用 `%s`、浮点用 `%f` 或 `%g`，就够覆盖绝大多数场景；下面这张表需要时再查。

| 动词        | 含义                                                     |
| ----------- | -------------------------------------------------------- |
| `%v`        | 默认格式                                                 |
| `%+v`       | 带字段名的结构体格式                                     |
| `%#v`       | Go 语法表示                                              |
| `%T`        | 类型                                                     |
| `%d`        | 十进制整数                                               |
| `%b`        | 二进制                                                   |
| `%o`        | 八进制                                                   |
| `%O`        | 带 `0o` 前缀的八进制                                     |
| `%x` / `%X` | 十六进制；作用于字符串或字节切片时输出每个字节的十六进制 |
| `%c`        | Unicode 字符                                             |
| `%U`        | Unicode 码点，形如 `U+4E2D`                              |
| `%q`        | 带引号的字符串或字符                                     |
| `%s`        | 字符串                                                   |
| `%t`        | 布尔值                                                   |
| `%f`        | 浮点数，默认保留 6 位小数                                |
| `%e` / `%E` | 科学计数法                                               |
| `%g`        | 紧凑浮点，按数值大小自动选择 `%f` 或 `%e`                |
| `%p`        | 指针地址                                                 |
| `%%`        | 百分号本身                                               |

浮点数最容易被 `%v` 骗到：`Println` 和 `%v` 对浮点数走的就是 `%g`，而 `%g` 的规则是“用能唯一还原该值的最短十进制形式”，所以整数形式的浮点**不显示小数点**，极大或极小的值会切成科学计数法：

```go
g := float64(10)

fmt.Println(g)           // 10 —— 不是 10.0，但 g 确实是 float64
fmt.Printf("%T %f\n", g, g) // float64 10.000000
fmt.Println(3.0)         // 3
fmt.Println(1e9)         // 1e+09
fmt.Println(1e-6)        // 1e-06

x, y := 1.0, 3.0

fmt.Println(x / y)       // 0.3333333333333333，最短可还原形式就是 16 位
```

同一段 `0.1 + 0.2` 打出来是 `0.3` 还是 `0.30000000000000004`，差别不在格式而在这两个值本身：一个是编译期的精确常量，一个是运行时的 `float64` 值（见上文“浮点类型”一节）。`%g` 只是把各自的**值**如实显示成最短可还原形式。

想固定小数位就用 `%f`（默认 6 位）或 `%.2f` 这类带精度的写法；想确认一个值到底是什么类型，用 `%T`——`Println` 只打值、不打类型。

打印单个字符用 `%c`，打印它的码点用 `%U` 或 `%d`：

```go
fmt.Printf("%c", 65)  // A
fmt.Printf("%U", '中') // U+4E2D
```

`%x` 作用于字符串时，输出的是**每个字节**的十六进制，而不是把整个字符串当成一个数：

```go
fmt.Printf("%x", "Go") // 476f
```

### 宽度、精度和标志

格式动词前可以指定宽度、精度和对齐方式：

```go
fmt.Printf("%5d", 42)
fmt.Printf("%-5d", 42)
fmt.Printf("%05d", 42)
fmt.Printf("%6.2f", 3.14159)
fmt.Printf("%+d", 42)
fmt.Printf("% d", 42)
```

对应的输出形态分别是：

```text
   42
42
00042
  3.14
+42
 42
```

`%+d` 强制显示正号，`% d` 用空格代替正号，后者在需要对齐正负数的场景很有用。宽度是**最小**宽度，实际内容更长时不会被截断；精度对小数为保留位数，对字符串为最大字符数。

前面动词表里的 `%p` 用于打印指针地址，`&`、`*` 和指针本身的规则见 `10-指针.md`。
