# 03 控制流

> Go 版本：>= 1.27.1  

Go 的控制流只有 `if`、`for`、`switch`、`goto` 四种结构（没有 `while`，也没有 `do-while`）：本篇讲它们的写法，以及 `break`/`continue` 与标签怎么配合。

示例里会出现切片和 map 的遍历写法，它们的类型细节分别见 `07-切片.md` 和 `08-map.md`；`range` 遍历整数见下文"range over int"，遍历迭代器函数见 `14-迭代器.md`。

## 条件分支 if

`if` 用于条件判断。条件必须是 `bool`，不需要括号：

```go
age := 18

if age >= 18 {
    fmt.Println("adult")
} else {
    fmt.Println("minor")
}
```

`else if` 可以继续判断：

```go
score := 85

if score >= 90 {
    fmt.Println("A")
} else if score >= 80 {
    fmt.Println("B")
} else {
    fmt.Println("C")
}
```

`if` 可以带一个初始化语句，该语句中声明的变量只在 `if` 和 `else` 内部可见：

```go
if n := len("golang"); n > 5 {
    fmt.Println(n) // 6
}
```

### 作用域

`if` 中的初始化变量不会泄漏到外部：

```go
if x := 10; x > 5 {
    fmt.Println(x)
}

// fmt.Println(x) // 非法，x 已经离开作用域
```

## 循环 for

Go 只有 `for` 一种循环关键字，但可以写出几种常见形式。

### 完整形式

```go
sum := 0

for i := 0; i < 5; i++ {
    sum += i
}

fmt.Println(sum) // 10
```

初始化语句、条件表达式和后置语句都可以省略。

### 只有条件

```go
n := 0

for n < 5 {
    n++
}
```

### 无限循环

```go
for {
    // 通常需要在某个条件下 break
    break
}
```

### range

`range` 用于遍历数组、切片、字符串、map、channel，以及整数和迭代器函数。后两者是较新的语言特性：遍历整数见本节末尾的"range over int"，遍历迭代器函数见 `14-迭代器.md`。

下面的例子用切片和 map 演示 `range` 的写法；它们的类型细节要到 `07-切片.md`、`08-map.md` 才讲，这里先照着用。

遍历切片：

```go
nums := []int{10, 20, 30}

for i, v := range nums {
    fmt.Println(i, v) // 0 10 / 1 20 / 2 30
}
```

如果只需要值，可以忽略索引：

```go
for _, v := range nums {
    fmt.Println(v) // 10 20 30
}
```

如果只需要索引：

```go
for i := range nums {
    fmt.Println(i) // 0 1 2，只要索引时第二个变量可以省掉
}
```

遍历字符串时，索引是字节位置，值是对应的 `rune`：

```go
for i, r := range "Go语言" {
    fmt.Println(i, r) // 0 71 / 1 111 / 2 35821 / 5 35328 —— 索引是字节位置
}
```

遇到非法 UTF-8 字节时，`range` 会产出 `utf8.RuneError`（即 `U+FFFD`）并且只前进一个字节。所以只要数据来自外部，就不要假设遍历出的字符数等于 `len(s)`，也不要假设值一定是有意义的字符——逐字节的对照示例与校验方式见 `20-字符串与字节.md`。

遍历 map：

```go
m := map[string]int{"a": 1, "b": 2}

for k, v := range m {
    fmt.Println(k, v) // 顺序随机，不要依赖 a、b 的先后
}
```

map 的遍历顺序是随机的，不能依赖某一种顺序；遍历期间增删元素的行为、以及需要稳定顺序时的排序写法见 `08-map.md`。

遍历 nil 切片或 nil map 是安全的，循环次数为 0：

```go
var nums []int
var m map[string]int

for range nums {
    fmt.Println("不会执行")
}

for range m {
    fmt.Println("不会执行")
}
```

### range over int

Go 1.22 起，`range` 可以直接遍历整数，从 `0` 到 `n-1`：

```go
for i := range 5 {
    fmt.Println(i) // 0 1 2 3 4
}
```

## 循环变量

Go 1.22 起，每次循环迭代都有自己独立的循环变量。

下面这段要用到切片、`append` 和闭包，它们的语法分别见 `07-切片.md` 和 `04-函数.md`；还没读到那两篇的话，先记住结论，回头再看这段代码也一样。

```go
var funcs []func()

for i := 0; i < 3; i++ {
    funcs = append(funcs, func() {
        fmt.Println(i)
    })
}

for _, f := range funcs {
    f()
}
```

这段代码会输出 `0`、`1`、`2`。在 Go 1.22 之前，闭包可能捕获到同一个变量，从而输出多个 `3`。写现代 Go 代码时，可以按新语义理解循环变量。

## switch（表达式 switch）

`switch` 用于多分支判断。Go 的 `switch` 默认不会继续执行下一个 `case`：

```go
day := "Mon"

switch day {
case "Mon", "Tue", "Wed", "Thu", "Fri":
    fmt.Println("workday")
case "Sat", "Sun":
    fmt.Println("weekend")
default:
    fmt.Println("unknown")
}
```

`switch` 也可以带初始化语句：

```go
switch n := len("golang"); n {
case 0:
    fmt.Println("empty")
case 1:
    fmt.Println("one")
default:
    fmt.Println(n) // 6，len("golang") 既不匹配 0 也不匹配 1
}
```

不带表达式的 `switch` 相当于 `switch true`：

```go
score := 85

switch {
case score >= 90:
    fmt.Println("A")
case score >= 80:
    fmt.Println("B")
default:
    fmt.Println("C")
}
```

需要继续执行下一个 `case` 时，可以使用 `fallthrough`：

```go
switch n := 1; n {
case 1:
    fmt.Println("one")
    fallthrough
case 2:
    fmt.Println("two")
}
```

`fallthrough` 会无条件进入下一个 `case`，不能带条件，也不能用于类型 switch。实际开发中极少使用：共享逻辑用 `case A, B, C:` 逗号合并更清晰；有层次关系时直接显式赋值，比隐式穿透更容易维护。

## 标签与 break、continue

这一节里的三件事要分开看：`break` 是"结束本层"，`continue` 是"跳过本层这一次"，而标签只是**给语句起个名字**。标签本身不改变任何行为，它只让 `break`、`continue`、`goto` 能指名道姓地作用到某一层上。

### break：只跳出最内层

`break` 默认只跳出最内层的 `for`、`switch` 或 `select`。下面这段里 `break` 只结束 `switch`，`for` 照常进入下一次迭代：

```go
for i := 0; i < 3; i++ {
    switch i {
    case 1:
        break // 只跳出 switch，for 继续
    }
    fmt.Println(i) // 0 1 2
}
```

所以光写 `break` 无法跳出外层循环，想跳出得用标签（见下文“break 与标签：跳出指定层”一节）。

`select` 里的 `break` 同理，只结束 `select` 本身，见 `38-并发基础.md`。

### continue：只跳过本层的一次迭代

`continue` 不结束循环，只是放弃本次迭代剩下的代码，直接开始下一次：

```go
for i := 0; i < 5; i++ {
    if i%2 == 0 {
        continue // 跳过偶数
    }
    fmt.Println(i) // 1 3
}
```

`continue` 只能作用于 `for`。写在 `for` 内部的 `switch` 里时，作用的仍然是外面那个 `for`——`switch` 自己没有"下一次迭代"：

```go
for i := 0; i < 5; i++ {
    switch {
    case i%2 == 0:
        continue // 作用于 for，不是 switch
    }
    fmt.Println(i) // 1 3
}
```

### 标签

标签就是写在语句前一行的一个名字加冒号，用来给这条语句起名：

```go
loop:
for i := 0; i < 3; i++ {
    if i == 2 {
        break loop // 结束标着 loop 的那个循环
    }
    fmt.Println(i) // 0 1
}
```

规则如下：

- 标签名写在目标语句的前一行，末尾是冒号；`gofmt` 会把标签顶格，不要跟着代码一起缩进。
- 配合 `break`、`continue` 使用时，标签必须标在 `for`、`switch` 或 `select` 上；配合 `goto` 时可以标在任意语句上（见下文“goto 跳转”一节）。
- 标签在整个函数内可见，同一个名字不能出现两次，重复定义会报 `label outer already defined at ...`。
- 标签必须被用到。把上面例子里的 `break loop` 改成 `break`，`loop:` 就成了未使用的标签，编译直接失败：

  ```text
  label loop defined and not used
  ```

  换句话说，**不存在"加了标签却不改变行为"的写法**：标签要么被 `break`、`continue`、`goto` 用上，要么就编译不过。

上面这段只有一层循环，`break loop` 和 `break` 的效果完全一样；标签的价值要到多层嵌套时才体现出来。

### break 与标签：跳出指定层

给外层循环加上标签后，`break 标签` 就能结束指定的那一层。它和本节第一个例子只差一个 `loop`，输出却从 `0 1 2` 变成了 `0`：

```go
loop:
for i := 0; i < 3; i++ {
    switch i {
    case 1:
        break loop // 结束整个 for，而不是只跳出 switch
    }
    fmt.Println(i) // 0
}
```

嵌套循环里也一样，`break outer` 一次结束两层：

```go
outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if j == 1 {
            break outer
        }
        fmt.Println(i, j) // 0 0
    }
}
```

如果标签标的不是 `for`、`switch`、`select`，`break 标签` 会报编译错误 `invalid break label outer`。

### continue 与标签：跳到指定层的下一次迭代

`continue 标签` 跳到指定那一层的下一次迭代。下面这段一旦进入内层就会立刻重来外层，所以 `j` 永远停在 0：

```go
outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if j == 1 {
            continue outer // 放弃外层本次迭代的剩余部分
        }
        fmt.Println(i, j) // 0 0 / 1 0 / 2 0
    }
}
```

和 `break outer` 的区别是：`continue outer` 只放弃外层本次迭代剩下的部分，外层还会继续跑；`break outer` 则直接结束外层循环。把上例的 `continue` 换成 `break`，输出就只剩 `0 0`。

`continue` 的标签必须标在 `for` 上，标在 `switch` 上会报编译错误 `invalid continue label sw`，因为 `switch` 没有"下一次迭代"。

### 使用建议

标签是"一次跳出多层"的手段，代价是可读性：读代码的人要回头找标签到底标在哪一层。能用别的写法时优先用别的写法——把循环体抽成函数再提前 `return`、用一个 `bool` 标志写进循环条件、把"找到就停"的判断挪到循环外面。只有确实要跨两层以上时才用标签，并且给它起个看得懂的名字（`outer`、`rows` 之类）。

## goto 跳转

`goto` 可以跳转到同一函数内的标签（标签的写法与命名规则见上文“标签”一节）。它很少使用，通常只在极少数清理逻辑或生成代码中出现：

```go
i := 0

loop:
if i < 3 {
    i++
    goto loop
}
```

日常代码中应优先使用 `for`、`break` 和 `continue`，可读性更好。
