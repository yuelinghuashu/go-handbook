# 27 日志

> Go 版本：>= 1.27.1  
> 相关标准库：log、log/slog

需要给程序加日志时，本篇解决"用 `log` 还是 `log/slog`、Handler 怎么选"的问题：`log` 提供最基础的全局日志，`log/slog` 提供结构化日志（级别、属性、Handler），文末还有两者互相桥接的写法。UUID 已独立成篇，见 `28-UUID.md`。

## log

```go
log.Println("server starting")
log.Printf("listen on %s", addr)
```

默认输出会带日期和时间：

```text
2026/08/28 12:00:00 server starting
```

### Fatal 和 Panic

```go
log.Fatal("cannot continue")
log.Panic("unexpected error")
```

`log.Fatal` 会输出日志后调用 `os.Exit(1)`，`defer` 不会执行。`log.Panic` 会触发 panic。

### 自定义 Logger

```go
logger := log.New(os.Stdout, "app: ", log.LstdFlags|log.Lshortfile)

logger.Println("hello")
```

常用 flag：

- `log.Ldate`
- `log.Ltime`
- `log.Lmicroseconds`
- `log.Lshortfile`
- `log.Llongfile`
- `log.LstdFlags`

### 设置默认 logger

```go
log.SetPrefix("app: ")
log.SetFlags(log.LstdFlags | log.Lshortfile)
log.SetOutput(os.Stdout)
```

### 输出到文件或缓冲区

`log.New` 和 `Logger.SetOutput` 接收任意 `io.Writer`，所以可以把日志同时写到终端和缓冲区（也方便测试断言）：

```go
var buf bytes.Buffer

logger := log.New(io.MultiWriter(os.Stdout, &buf), "app: ", log.LstdFlags|log.Lshortfile)

logger.Println("hello")
fmt.Print(buf.String()) // 形如 app: 2026/08/28 12:00:00 main.go:5: hello —— 日期、时间、文件名和行号都随运行变化，不是固定输出
```

切换输出目标时直接在原来的 `*log.Logger` 上调用 `SetOutput` 即可（它只影响这个 logger，包级默认 logger 用 `log.SetOutput`）：

```go
f, err := os.OpenFile("app.log", os.O_CREATE|os.O_WRONLY|os.O_APPEND, 0o644)
if err != nil {
    return err
}

logger.SetOutput(f)
```

`log.Fatal` 和 `log.Panic` 的行为不受输出目标影响：输出日志之后仍然会调用 `os.Exit(1)` / 触发 panic。

## log/slog

`log/slog` 是结构化日志包，适合生产环境。**选哪个先看这里**：脚本、小工具、只有"打一行提示"的需求，用 `log` 就够了；服务端要按级别过滤、要输出 JSON 交给采集系统（ELK、Loki 之类）、要带固定的请求字段，就用 `slog`。Handler 的选择同理——开发时 `TextHandler` 人眼好读，上线后换 `JSONHandler` 给机器读，两者接口一样，换起来只改一行。

这一节前半讲用法（Handler、级别、属性），后半（`## 扩展 slog` 起）讲扩展：让类型自己决定怎么输出、写自定义 Handler、以及和 `log` 互相桥接。

```go
slog.Info("server starting", "addr", ":8080")
slog.Warn("slow request", "path", "/api", "duration", 500)
slog.Error("request failed", "err", err)
```

### TextHandler

```go
logger := slog.New(slog.NewTextHandler(os.Stdout, nil))
logger.Info("hello", "count", 3)
```

输出类似：

```text
time=2026-08-28T12:00:00.000+08:00 level=INFO msg=hello count=3
```

### JSONHandler

```go
logger := slog.New(slog.NewJSONHandler(os.Stdout, nil))
logger.Info("hello", "count", 3)
```

输出：

```json
{"time":"2026-08-28T12:00:00.000+08:00","level":"INFO","msg":"hello","count":3}
```

### 设置默认 logger

```go
slog.SetDefault(logger)
```

设置后，顶层函数和 `log` 包默认 logger 都会使用新的 handler。

### 日志级别

```go
opts := &slog.HandlerOptions{
    Level: slog.LevelDebug,
}

logger := slog.New(slog.NewTextHandler(os.Stdout, opts))
logger.Debug("debug message")
```

动态调整级别：

```go
var level slog.LevelVar
level.Set(slog.LevelDebug)

opts := &slog.HandlerOptions{
    Level: &level,
}

logger := slog.New(slog.NewTextHandler(os.Stdout, opts))
```

### 固定属性

```go
logger := slog.New(slog.NewTextHandler(os.Stdout, nil))
logger = logger.With("service", "api", "env", "dev")

logger.Info("started")
```

### 分组

```go
logger = logger.WithGroup("http")

logger.Info("request", "method", "GET", "path", "/")
```

### LogAttrs 与 Attr：少一层分配

`logger.Info("msg", "k", v)` 这种 `...any` 形式每次调用都要把 key/value 装进一个 `[]any`（通常逃逸到堆上）。`LogAttrs` 只接受 `[]slog.Attr`，省掉这层分配，是热路径上的推荐写法（它的第一个参数是 `context`，完整讲解见 `40-context.md`）：

```go
// LogAttrs 收 []slog.Attr；属性用 slog.Xxx 构造：String / Int / Bool 按类型，
// Duration、Time 分别对应 time.Duration 与 time.Time，Any 用于其它任意值（会走反射）
logger.LogAttrs(ctx, slog.LevelInfo, "server starting",
    slog.String("addr", ":8080"),
    slog.Int("port", 8080),
    slog.Bool("tls", true),
    slog.Duration("timeout", 5*time.Second),
    slog.Time("at", time.Now()),
    slog.Any("err", err),
)
```

顶层也有对应的 `slog.LogAttrs`。`slog.Attr` 就是一个 `{Key string; Value Value}` 结构体；类型化的构造器有 `slog.String`、`slog.Int`、`slog.Int64`、`slog.Uint64`、`slog.Float64`、`slog.Bool`、`slog.Duration`、`slog.Time`，以及适用于任意值的 `slog.Any(key, v)`。单独构造 `Value` 用 `slog.StringValue`、`slog.Int64Value`、`slog.AnyValue`、`slog.GroupValue`。

### Group：嵌套结构

`logger.WithGroup` 影响它之后的所有属性，而 `slog.Group` 只把一组属性嵌套在一层里：

```go
// Group：把一组属性嵌到一层里（区别于 WithGroup 会影响它之后的所有属性）
logger.LogAttrs(ctx, slog.LevelInfo, "request",
    slog.String("method", "GET"),
    slog.Group("http",
        slog.Int("status", 200),
        slog.Duration("took", 12*time.Millisecond),
    ),
)
```

TextHandler 用点号展开，JSONHandler 输出真正的嵌套对象（`Duration` 在 JSON 里是纳秒整数）：

```text
time=2026-08-28T12:00:00.000+08:00 level=INFO msg=request method=GET http.status=200 http.took=12ms
```

```json
{"time":"2026-08-28T12:00:00.000+08:00","level":"INFO","msg":"request","method":"GET","http":{"status":200,"took":12000000}}
```

### 记录源码位置

`HandlerOptions.AddSource` 为每条记录附上 `slog.Source`（函数名、文件、行号）：

```go
logger := slog.New(slog.NewJSONHandler(os.Stdout, &slog.HandlerOptions{
    AddSource: true,
}))

logger.Info("hello")
// {"time":"...","level":"INFO","source":{"function":"main.main","file":"/app/main.go","line":12},"msg":"hello"}
```

`slog.Source` 的字段是 `Function`、`File`、`Line`；`AddSource` 是 `HandlerOptions` 的字段（`slog` 包里没有同名的顶层函数）。取运行时栈有开销，只建议在调试或低频日志上打开。

## 扩展 slog

下面几节都超出"直接调 `slog.Info`"的范围：让类型自己决定怎么输出、写自定义 Handler、以及和 `log` 互相桥接。

### LogValuer：让类型自己决定怎么输出

实现 `LogValuer`（一个 `LogValue() slog.Value` 方法）之后，这个类型的值作为属性时会被自动展开：

```go
type Money struct {
    Cents int64
}

func (m Money) LogValue() slog.Value {
    return slog.GroupValue(
        slog.Int64("cents", m.Cents),
        slog.String("currency", "CNY"),
    )
}

type Latency time.Duration

func (d Latency) LogValue() slog.Value {
    return slog.StringValue(time.Duration(d).Round(time.Millisecond).String())
}
```

```go
logger.Info("paid", "amount", Money{Cents: 1999}, "latency", Latency(1500*time.Millisecond))
// time=... level=INFO msg=paid amount.cents=1999 amount.currency=CNY latency=1.5s
```

`slog` 会用 `Value.Resolve` 反复调用 `LogValue`，直到拿到普通 `Value`（有调用次数上限，超过会变成一条错误值）；注意**group 里面的属性值不会再递归解析**。这个机制也常用来做**延迟求值**：只有这条日志真的会被输出时才去计算昂贵的字段。

### 自定义 Handler

`slog.Handler` 只有四个方法：

```go
type Handler interface {
    Enabled(ctx context.Context, level slog.Level) bool
    Handle(ctx context.Context, r slog.Record) error
    WithAttrs(attrs []slog.Attr) Handler
    WithGroup(name string) Handler
}
```

最小实现（把记录写成一行文本）：

```go
type myHandler struct{ w io.Writer }

func (h myHandler) Enabled(_ context.Context, l slog.Level) bool {
    return l >= slog.LevelInfo
}

func (h myHandler) Handle(_ context.Context, r slog.Record) error {
    fmt.Fprintf(h.w, "%s %s", r.Level, r.Message)

    r.Attrs(func(a slog.Attr) bool {
        fmt.Fprintf(h.w, " %s=%v", a.Key, a.Value)
        return true
    })

    return nil
}

// 简化实现：真实 handler 需要把预置属性和分组名带上
func (h myHandler) WithAttrs(attrs []slog.Attr) slog.Handler { return h }
func (h myHandler) WithGroup(name string) slog.Handler       { return h }
```

```go
logger := slog.New(myHandler{w: os.Stdout})
logger.Info("hello", "count", 3)
// INFO hello count=3
```

`slog.Record` 的导出字段是 `Time`、`Level`、`Message`、`PC`，属性通过 `r.Attrs` 遍历；需要 trace id 之类来自 `ctx` 的信息时，在 `Handle` 里直接读 `ctx`。真实实现要注意两点：`WithAttrs`/`WithGroup` 必须返回带上前缀状态的新 handler，`Handle` 必须并发安全。

### slog 与 log 的桥接

`slog.SetDefault` 之后，`log` 包默认 logger 的输出也会交给新的 handler：

```go
slog.SetDefault(slog.New(slog.NewJSONHandler(os.Stdout, nil)))

log.Println("hello from log")
// {"time":"...","level":"INFO","msg":"hello from log"}
```

也就是说 `log.Fatal`、`log.Panic` 的输出也会经过 slog handler，但它们“输出之后 `os.Exit(1)` / panic”的行为不变。log 包这一侧的级别由 `slog.SetLogLoggerLevel` 控制（默认 `Info`，`Debug` 以下的顶层调用不会进入 handler）。

反方向：第三方库只接受 `*log.Logger` 时，用 `slog.NewLogLogger` 把 `slog.Handler` 包成 `*log.Logger`：

```go
std := slog.NewLogLogger(slog.NewTextHandler(os.Stdout, nil), slog.LevelWarn)

std.Printf("library says: %s", "hi")
// time=2026-08-28T12:00:00.000+08:00 level=WARN msg="library says: hi"
```

它把 `Output` 调用转成一条 `slog.Record`，级别由第二个参数决定，内部的 `*log.Logger` 使用空前缀、零 flag，所以原来的日期/前缀格式不会再出现。

### MultiHandler

Go 1.26 起提供 `slog.MultiHandler`，可以把同一条日志发送给多个 handler：

```go
// NewMultiHandler：把同一条日志分发给多个 handler
// NewTextHandler / NewJSONHandler：分别输出 logfmt 风格文本与 JSON
handler := slog.NewMultiHandler(
    slog.NewTextHandler(os.Stdout, nil),
    slog.NewJSONHandler(os.Stderr, nil),
)

// New：用 handler 组装成 *slog.Logger，之后正常打日志即可
logger := slog.New(handler)
logger.Info("hello")
```
